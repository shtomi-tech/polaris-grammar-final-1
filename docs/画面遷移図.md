# 英文法トレーナー｜画面遷移図

作成日: 2026-07-29
対象: `C:\Users\shtom\dev\english-grammar-trainer`
基準: 現行実装（`shared/shell.js`、`shared/router.js`、各モジュールの `app.js`）

## 1. 対象範囲

この図は、統合後の単一アプリにおける画面と主要な操作の遷移を示す。

- 入口は `index.html` だけ。
- モジュールの切替はハッシュルートで行う。
  - `#/foundation`：基礎チェック
  - `#/grammar`：英文法演習
  - `#/reading`：英文解釈
- ハッシュがない、または不正な場合は `foundation` を表示する。
- 生徒切替・進捗保存・横断ナビゲーションは共通シェルが管理する。

## 2. 全体画面遷移図

```mermaid
flowchart TD
  start([アプリ起動]) --> shell[共通シェルを初期化]
  shell --> identity{生徒識別}
  identity -->|通常URL| local[端末内の生徒を選択]
  identity -->|共有URL ?s=...&t=...| cloud[認証済み生徒に固定<br/>クラウド進捗を読み込む]
  local --> route{ハッシュルートを判定}
  cloud --> route

  route -->|なし・不正| foundation[基礎チェック画面<br/>#/foundation]
  route -->|#/foundation| foundation
  route -->|#/grammar| grammarGate{基礎チェック5段階完了?}
  route -->|#/reading| reading[英文解釈画面<br/>#/reading]

  grammarGate -->|未完了| foundation
  grammarGate -->|完了| grammar[英文法演習画面<br/>#/grammar]

  foundation -. 共通フロー・次にやること .-> grammarGate
  grammar -. ポラリス完了後の推奨遷移 .-> reading

  studentChange[生徒切替・生徒追加] --> reload[同じルートを進捗付きで再読み込み]
  clear[この生徒の記録を全消去] --> reload
  reload --> route
```

## 3. 共通シェルの画面要素

各ルートの本文の外側には、次の共通要素が表示される。

| 要素 | 遷移・動作 |
|---|---|
| 生徒選択 | ローカルモードで生徒を切り替え、現在のハッシュルートを再読み込みする |
| 生徒追加 | 生徒名を登録し、その生徒を選択した状態で現在のルートを再読み込みする |
| 学習フローナビ | `foundation`、`grammar`、`reading` を切り替える。未解放の英文法演習は押せない |
| 次にやること | `shared/flow.js` が進捗から推奨モジュールを決め、該当ルートへ移動する |
| フッターの記録削除 | 確認後、現在の生徒の3モジュール分の進捗を消去して現在のルートを再読み込みする |
| 共有状態表示 | 共有URL利用時はクラウド保存状態を表示する |

## 4. 基礎チェックの画面遷移

基礎チェックは、5段階を順番に進める4択演習である。

```mermaid
flowchart TD
  fHome[基礎チェック学習一覧]
  fQuiz[基礎チェック問題画面]
  fFeedback[正答・解説表示<br/>問題画面内の状態]
  fResult[結果画面]
  fReview[誤答・弱点の解説画面]
  fNext[次の段階]
  gRoute[英文法演習へ]

  fHome -->|第1段階から始める<br/>未完了の段階から始める| fQuiz
  fHome -->|途中から再開する| fQuiz
  fQuiz -->|選択肢を選ぶ| fFeedback
  fFeedback -->|次の問題へ| fQuiz
  fFeedback -->|最後の問題で結果を見る| fResult
  fResult -->|次の段階へ進む| fNext
  fNext --> fQuiz
  fResult -->|弱点の解説を読む| fReview
  fReview -->|結果へ戻る| fResult
  fReview -->|解説後にもう一度全問を解く| fQuiz
  fResult -->|この段階・全体をもう一度解く| fQuiz
  fResult -->|学習一覧へ戻る| fHome
  fResult -->|5段階すべて完了| gRoute
```

### 基礎チェックの分岐条件

- 問題を選ぶと、その場で正誤・正答・解説を表示する。
- 各段階の最後まで回答すると結果画面へ進む。
- 結果画面では、次の段階、弱点解説、再演習、学習一覧を選べる。
- 5段階すべての `completed` が `true` になると、英文法演習が解放される。
- 途中保存がある場合は、問題番号・選択中の解答・解説確認状態を復元する。

## 5. 英文法演習の画面遷移

英文法演習は、基礎チェック完了前はゲート画面、完了後は3段階の学習ホームになる。

```mermaid
flowchart TD
  gGate[英文法演習ロック画面]
  gHome[英文法演習ホーム<br/>Master Path・進捗・教材一覧]
  gSelect[自由演習の条件選択<br/>単元・セット・出題モード]
  gQuiz[英文法4択問題画面]
  gResult[演習完了画面]
  gReview[誤答復習セッション]
  gSpaced[間隔復習セッション]
  step2[Step 2 ランダム制覇]
  step3[Step 3 30問連続正解]
  rRoute[英文解釈へ]
  fRoute[基礎チェックへ]

  gGate -->|基礎学習を続ける| fRoute
  fRoute -->|5段階完了後| gHome

  gHome -->|UNITを選ぶ| gQuiz
  gHome -->|自由演習を開く| gSelect
  gSelect -->|セット10問・全範囲10問| gQuiz
  gHome -->|途中保存を再開| gQuiz
  gHome -->|今日の復習| gSpaced
  gHome -->|誤答を復習| gReview
  gHome -->|Step 2開始| step2
  gHome -->|Step 3開始| step3

  step2 --> gQuiz
  step3 --> gQuiz
  gReview --> gQuiz
  gSpaced --> gQuiz

  gQuiz -->|解答| gQuizFeedback[正解・不正解・解説<br/>問題画面内の状態]
  gQuizFeedback -->|次の問題| gQuiz
  gQuizFeedback -->|最後の問題| gResult

  gResult -->|次にやること| gHome
  gResult -->|誤答を復習| gReview
  gResult -->|Step 2・Step 3・間隔復習| gQuiz
  gResult -->|ポラリス完了| rRoute
  gResult -->|学習一覧へ戻る| gHome
```

### 英文法演習の解放条件

| 段階 | 内容 | 解放条件 |
|---|---|---|
| ゲート | 基礎チェックへの誘導 | 基礎チェック5段階が未完了 |
| Step 1 | UNIT演習 | 基礎チェック5段階完了で利用可能 |
| Step 2 | 未クリア問題のランダム制覇 | Step 1の全問題を `step1Cleared` |
| Step 3 | 30問連続正解チャレンジ | Step 2の全問題を `step2Cleared` |
| 間隔復習 | 1・3・7・14日後の復習 | Step 2の正解問題に復習予定日が設定される |
| 英文解釈 | 次の推奨学習 | Step 3で `mastered` 達成 |

### 英文法演習のセッション種別

- `step1`：選択したUNITの演習
- `step1Wrong`：Step 1の誤答演習
- `step2`：未クリア問題からのランダム演習
- `step2Single`：ヒートマップから選んだ1問の確認
- `step3`：30問連続正解チャレンジ
- `setAll`：選択したセットの自由演習
- `tenTest`：全範囲からランダム10問
- `review`：未解決の誤答復習
- `spaced`：今日が復習予定日の問題

これらは別画面ではなく、同じ問題画面をセッション種別ごとに使い分ける。

## 6. 英文解釈の画面遷移

英文解釈は、教材を選択して1英文を3ステップで確認する。推奨導線は英文法演習の後だが、ルート自体は先に開ける。

```mermaid
flowchart TD
  rHome[英文解釈 学習画面<br/>開始CTA・教材一覧・進捗]
  rWorkspace1[Step 1 英文を分析]
  rWorkspace2[Step 2 正解と比較]
  rWorkspace3[Step 3 解説を確認]
  rDone[教材完了状態]
  rReview[復習対象として登録]
  rNext[次の教材]
  rGrammar[英文法演習へ戻る]

  rHome -->|つづきから・最初の問題| rWorkspace1
  rHome -->|教材一覧から選ぶ| rWorkspace1
  rHome -->|保存済みのStepから再開| rWorkspace1
  rHome -->|復習対象を選ぶ| rReview
  rReview --> rWorkspace1

  rWorkspace1 -->|英文を / で区切る| rWorkspace1
  rWorkspace1 -->|区切りを分析する| rWorkspace1
  rWorkspace1 -->|文の要素・文型を入力して比較| rWorkspace2
  rWorkspace2 -->|解説へ進む| rWorkspace3
  rWorkspace2 -->|Step 1に戻る| rWorkspace1
  rWorkspace2 -->|あとで復習する| rReview
  rWorkspace3 -->|チェックポイントを確認| rWorkspace3
  rWorkspace3 -->|次の問題へ| rNext
  rNext --> rWorkspace1
  rWorkspace3 -->|最後の教材を完了| rDone
  rDone -->|教材一覧を開く| rHome
  rDone -->|学習ホームへ戻る| rGrammar
  rWorkspace3 -->|あとで復習する| rReview
```

### 英文解釈の内部状態

| 状態 | 主な操作 | 次の状態 |
|---|---|---|
| `first` | スラッシュ分割、文の要素、文型、自分の訳を入力 | 準備完了後に `compare` |
| `compare` | 自分の分析と先生データを比較 | `input` または `first` |
| `input` | 解析・指針・解説・和訳例・語句を確認 | チェック後に次の教材または完了 |
| 復習対象 | 「あとで復習する」で登録 | 学習画面の復習一覧へ戻る |

## 7. 教材編集画面

教材編集は通常の生徒画面には表示されず、`#/reading?mode=editor` でのみ有効になる。

```mermaid
flowchart LR
  readingRoute[英文解釈<br/>#/reading?mode=editor] --> learn[学習タブ]
  readingRoute --> editor[先生・教材編集タブ]
  editor --> load[JSONを読み込む]
  editor --> download[教材JSONを保存]
  editor --> add[空の項目を追加]
  editor --> clear[この生徒の進捗を全消去]
  load --> learn
  learn --> editor
```

編集画面は教材JSONを扱う管理用の画面であり、生徒向け学習導線には含めない。

## 8. 保存・再開に関する補足

- 生徒ごとの統合進捗は `egt.progress.<生徒ID>` に保存する。
- クラウド同期は共有URLで認証された場合だけ有効になる。
- 生徒を切り替えると、同じルートを新しい生徒の進捗で再描画する。
- 基礎チェックは `inProgress` を復元する。
- 英文法演習は `__session` を復元する。
- 英文解釈は教材ごとの `lastItemId` と `lastStep` を復元する。
- 画面を閉じても、次回の「次にやること」または各モジュールのCTAから再開できる。
