# 完了形と節の時間関係

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

完了形は、ある基準時より前を示す形です。主節と従属節の時計を別々に置くと、過去完了・未来完了・時や条件の副詞節を一つの手順で読めます。

## 1. 完了形は基準時より前を見る

:::board
had + 過去分詞 → 過去の基準時より前
will have + 過去分詞 → 未来の基準時より前
:::

`have` の時制が基準時を決め、過去分詞が「そこより前」を示します。完了形を見たら、何より前なのかを文中から探します。

:::check check-tense-perfect-clauses-01
question: 次の文の空所に入る語は? Andrew ( ) in the hospital for ten days when I visited him.
choice: A|had been
choice: B|has been
answer: A
explanation: when I visited him が過去の基準時です。その時点より前から10日間入院していたので、had + 過去分詞 の過去完了 had been を使います。文全体は「私が訪ねたとき、アンドリューは10日間入院していた」です。
:::


## 2. 過去完了は過去の二つの出来事を並べる

:::board
When I arrived, the train had left.
先に起きたこと: had left
後の基準時: arrived
:::

過去のある時点よりさらに前に完了していたことは過去完了です。二つの出来事が同じ順で起きたとは限らないため、時間関係を図にします。

:::check check-tense-perfect-clauses-02
question: 次の文の空所に入る語は? The suspect ( ) away when the police arrived.
choice: B|had already run
choice: A|already ran
answer: B
explanation: arrived という過去の基準時より前に、容疑者はすでに逃げていました。過去を基準にそれより前を表す had already run を使います。
:::


## 3. before節は前後関係を確認する

:::board
She left before I arrived.
She had left before I arrived.
:::

`before` があれば前後関係はすでに示されています。過去完了を使うかは、過去の基準時より前であることを強調する必要があるか、文脈と選択肢全体で判断します。

:::check check-tense-perfect-clauses-03
question: 次の文の空所に入る語は? ( ) ever played the clarinet before you entered high school?
choice: A|Had you
choice: B|Have you
answer: A
explanation: before you entered high school という過去の基準時より前の経験を尋ねているので、疑問文でも過去完了 Had you を使います。
:::


## 4. 未来完了は未来の締切までに終わる

:::board
By next June, I will have finished the course.
未来の基準時: next June
:::

`by` などで未来の基準時を置き、その時までに完了していることを表すのが未来完了です。`will` の後ろは原形、`have` の後ろは過去分詞です。

:::check check-tense-perfect-clauses-04
question: 次の文の空所に入る語は? We're late! The train ( ) by the time we arrive.
choice: B|will have left
choice: A|has left
answer: B
explanation: by the time we arrive という未来の基準時までに完了していることを表すので、未来完了 will have left を使います。
:::


## 5. 時・条件の副詞節では未来でも現在形を使う

:::board
When I arrive, I will call you.
If it rains, we will stay home.
:::

`when` や `if` が未来の条件・時を表す副詞節では、節の中に通常 `will` を置きません。未来の結果を表す主節と、条件を置く節の役割を分けます。

:::check check-tense-perfect-clauses-05
question: 次の文の空所に入る語は? Ken will study in Canada after he ( ) from high school.
choice: A|graduates
choice: B|will graduate
answer: A
explanation: 未来のことでも、時を表す副詞節 after の中では一般に現在形を使います。
:::


## 6. 名詞節の未来は節の働きを見る

:::board
I don't know when he will arrive.
疑問を内容として受ける名詞節 → will可
:::

同じ `when` でも、時を表す副詞節ではなく、動詞の目的語となる名詞節なら未来の `will` を使えます。接続詞の後ろだけを機械的に決めません。

:::check check-tense-perfect-clauses-06
question: 次の文の空所に入る語は? I don't know when he ( ) back.
choice: B|will come
choice: A|comes
answer: B
explanation: when he ... back は動詞 know の目的語になる名詞節であり、時を表す副詞節ではない。名詞節の中では未来の内容を will でそのまま表す。
:::


## 7. 時制の一致と完了形を組み合わせる

:::board
主節の基準時を置く
→ その時より前か確認する
→ 節の働きと未来・過去を決める
:::

時制の総合問題では、完了形だけを探さず、主節・従属節・名詞節の関係を分けます。時計を三つ並べると、選択肢の形が絞れます。

:::check check-tense-perfect-clauses-07
question: 次の文の空所に入る語は? By the time we arrived, the concert ( ).
choice: A|had begun
choice: B|begins
answer: A
explanation: we arrived という過去の基準時より前に始まっていたので、過去完了 had begun を使います。
:::


## 8. 現在形にしたあとも主語の一致と態を確認する

:::board
if/whenの節を現在形にするのは最初の一歩
① 主語は単数か複数か → be動詞の形
② 主語は動作をする側かされる側か → 能動か受動か
:::

if/when節の中を「未来のことでも現在形」にしただけでは終わりません。同じ節の中でも、主語が単数か複数かでbe動詞の形が変わり、主語が動作をする側かされる側かで能動と受動のどちらを使うかが変わります。DDTのような薬剤は自分で「使う」側ではなく「使われる」側なので、受動態にしたうえで、主語の数に合わせてis/areを選びます。

:::check check-tense-perfect-clauses-08
question: 次の文の空所に入る語は? If these chemicals ( ) carelessly, they will harm the environment.
choice: A|are used
choice: B|is used
answer: A
explanation: chemicals は複数の主語で、「使われる」側なので、受動態の現在形 are used にします。
:::
