# 仮定法の発展・提案・倒置

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

発展では、条件と結果の時点がずれるほか、`if` が別の語や倒置に変わります。基本と同じく、現実・条件・結果を分けてから構文を戻します。

## 1. 混合仮定法は条件と結果の時計が違う

:::board
If S had + p.p.,
S would + 原形
過去の条件 → 現在の結果
:::

`If I had taken the job, I would live in London now.` は、過去の選択が現在の状態に影響する形です。条件は過去完了、結果は現在の反実仮想にします。

## 2. should・were to は未来の低い可能性

:::board
If S should + 原形: 万一～なら
If S were to + 原形: 仮に～なら
:::

`If you should need help` の `should` は義務ではなく、未来の可能性を控えめに示します。`were to` も現実から距離を置く未来の仮定です。

## 3. if を使わない条件を読み替える

:::board
without + 名詞: ～がなければ
but for + 名詞: ～がなければ
even if + 節: たとえ～でも
:::

`Without your help, I could not have finished.` は、助けがあったことを条件として捉えます。`even if` は条件を認めても結果が変わらない譲歩なので、意味の向きも確認します。

## 4. wish・if only は願いの時点を見る

:::board
wish + 過去形: 今の願い
wish + had + p.p.: 過去への後悔
if only + 過去形 / had + p.p.
:::

`I wish I were taller.` は現在の願い、`I wish I had studied harder.` は過去への後悔です。`if only` も同じ時間差を持つので、いつの事実と反対かを確認します。

## 5. as if は主節との前後関係で決める

:::board
as if + 過去形: 同時の非現実
as if + had + p.p.: それより前の非現実
:::

`He talks as if he knew everything.` は今の話し方と反対の仮定、`as if he had seen it` は主節より前の出来事です。形だけでなく時間の前後を見ます。

## 6. if の省略は倒置から元の形へ戻す

:::board
Had I known = If I had known
Were I you = If I were you
Should you need help = If you should need help
:::

文頭の `Had/Were/Should` と主語の入れ替わりを見たら、`if` を補います。倒置を元に戻してから、現在・過去・未来のどの仮定かを判断します。

## 7. 提案の that節は原形を保つ

:::board
suggest that S + 原形
suggest that S should + 原形
:::

`I suggested that he take a rest.` の `take` は原形です。`suggest 人 to do` と決めつけず、提案の内容を表す that節の骨格を確認します。

## 8. It's time that は現在への促し

:::board
It's time (that) S + 過去形
「もう～する時間だ」
:::

`It's time that you went to bed.` は、過去の出来事ではなく「もう寝る時間だ」という現在への促しです。形の過去と時間の意味を分けます。

## 9. 発展問題は構文を共通の手順へ戻す

:::board
1. if を探す・補う
2. 条件と結果を分ける
3. それぞれの時点を決める
4. wish/as if/suggest の型を照合
:::

混合仮定法・without・倒置が出ても、条件・結果・現実の関係へ戻します。最後に構文固有の形を照合し、単語一つの印象で選ばないようにします。
