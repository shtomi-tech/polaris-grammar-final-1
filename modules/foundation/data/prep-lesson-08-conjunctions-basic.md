# 接続詞の基本

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

接続詞は、語・句・節をつなぐ部品です。まず前後の形が対等かを見て、次に内容の関係を読みます。ここでは`and / but / or / so`に絞り、詳しい従属節は後の単元に渡します。

:::board
この単元の問い
「何と何を、どんな関係でつないでいる？」
:::

## 1. 前後は同じ働きのまとまりか

:::board
語 + 語
句 + 句
節 + 節
:::

`She is intelligent and hardworking.`は形容詞どうし、`You can take a bus or walk`は動作のまとまりどうしです。接続詞の前後が同じ働きなら、対等につないでいると考えます。

:::check check-12-conjunctions-basic-01
question: 次の文の空所に入る語は? You can take a bus ( ) walk to the station.
choice: A|or
choice: B|because
answer: A
explanation: a bus と walk という選択肢を対等につなぐので or が適切です。
:::


## 2. andは追加・つながりを表す

:::board
intelligent and hardworking
Study hard, and you will improve.
:::

`and`は単純な追加だけでなく、命令のあとに続く結果や流れも表します。前後がどのようにつながるかを読み、語の訳だけで決めません。

:::check check-12-conjunctions-basic-02
question: 次の文の空所に入る語は? Study hard, ( ) you will get a good score on the test.
choice: B|and
choice: A|or
answer: B
explanation: Study hard という命令の内容に続けて、その結果を you will get ... で述べています。命令文と結果の節をつなぐ and を使います。
:::


## 3. butは対比を表す

:::board
Tom wanted to go,
but it started to rain.
:::

前半から予想される内容と、後半が反対方向に進むなら`but`です。前後の主語や時制ではなく、内容の対比を確認します。

:::check check-12-conjunctions-basic-03
question: 次の文の空所に入る語は? Tom wanted to go, ( ) it started to rain.
choice: A|but
choice: B|and
answer: A
explanation: 前半と後半は「行きたかったが、雨が降り始めた」という対比なので、対等につなぐ but が適切です。and は追加、or は選択、so は結果を表しますが、この文の関係には合いません。
:::


## 4. orは選択・「さもないと」を表す

:::board
take a bus or walk
Hurry up, or you'll be late.
:::

二つの行動から選ぶときは`or`です。命令文の後ろでは「そうしなければ」という結果を表すこともあります。選択肢が二つあるかだけでなく、条件の関係も見ます。

:::check check-12-conjunctions-basic-04
question: 次の文の空所に入る語は? Hurry up, ( ) you'll be late for school.
choice: B|or
choice: A|but
answer: B
explanation: Hurry up, or ... は「急ぎなさい、さもないと~」という警告です。前半をしなければ後半になる関係なので or を使います。
:::


## 5. soは前の内容の結果を表す

:::board
worked hard, so she passed
原因・理由 → 結果
:::

前半が原因や理由、後半がその結果なら`so`です。`because`のように後ろを従属させる語ではなく、二つの節を対等につなぎます。

:::check check-12-conjunctions-basic-05
question: 次の文の空所に入る語は? Emily worked really hard this year, ( ) she passed the entrance examination.
choice: A|so
choice: B|yet
answer: A
explanation: 前半の「一生懸命勉強した」ことを受けて、後半に「合格した」という結果が続いています。独立した節どうしを等位に結ぶ so が適切です。
:::
