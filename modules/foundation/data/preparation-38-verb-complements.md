# 目的語に来る不定詞・動名詞

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

動詞の直後に「〜すること」を置くとき、`to + 動詞の原形`か`-ing`かは、前の動詞の型で決まります。まず、直接目的語なのか、目的語の後ろに続く型なのかを分けます。

## 1. 直接目的語の形を分ける

:::board
V + to do: decide to leave
V + doing: enjoy reading
V + O + to do: ask me to wait
:::

`to leave`や`reading`全体が前の動詞の目的語です。`ask me to wait`は「動詞＋目的語＋to不定詞」で、今回の直接目的語とは別の型です。

:::check check-38-verb-complements-01
question: 次の文の空所に入る語は? He enjoys ( ) novels.
choice: A|reading
choice: B|read
answer: A
explanation: enjoy は目的語として動名詞を取るので reading が適切です。
:::


## 2. to不定詞を取る動詞

:::board
decide / plan / hope + to do
hesitate + to do
:::

`decide to`、`plan to`、`hope to`、`hesitate to`のように、動詞ごとに後ろの形が決まります。`to`の後ろは原形です。

:::check check-38-verb-complements-02
question: 次の文の空所に入る語は? I am planning ( ) Kyoto next spring.
choice: B|to visit
choice: A|to visiting
answer: B
explanation: plan は不定詞を目的語に取る動詞であり、to の後ろは原形動詞になる。
:::


## 3. 動名詞を取る動詞・句動詞

:::board
enjoy / avoid / consider + doing
give up / put off + doing
:::

`enjoy reading`や`avoid talking`では、動名詞全体が動詞の目的語です。句動詞でも、`give up drinking`や`put off making`のように`-ing`を続けます。

:::check check-38-verb-complements-03
question: 次の文の空所に入る語は? They've put ( ) making their decision for another week.
choice: A|off
choice: B|away
answer: A
explanation: put off は「延期する」という句動詞です。後ろに making を置き、put off making their decision とします。
:::


## 4. 両方を取る動詞は時点・意味を見る

:::board
remember doing: したことを覚えている
remember to do: これからすることを忘れない
forget doing / forget to do
:::

両方の形を取れる動詞では、形だけでなく行為の時点を確認します。過去の経験か、これから行うことかを文脈から判断します。

:::check check-38-verb-complements-04
question: 次の文の空所に入る語は? I'll never forget ( ) Kofu when I was young.
choice: B|visiting
choice: A|to visit
answer: B
explanation: when I was young は過去に甲府を訪れた経験を示します。forget doing は「したことを忘れる」なので、forget visiting が適切です。
:::


## 5. stopは形で意味が変わる

:::board
stop doing: 〜することをやめる
stop to do: 〜するために立ち止まる
:::

`stop doing`は動作の中止、`stop to do`は別の目的のための停止です。日本語の「やめる」だけで決めず、後ろの動作との関係を読みます。

:::check check-38-verb-complements-05
question: 次の文の空所に入る語は? He stopped ( ) last year for his health.
choice: A|smoking
choice: B|to smoke
answer: A
explanation: stop + 動名詞 は「~することをやめる」という意味。
:::


## 6. regretなどの型も文脈で確認する

:::board
regret doing: したことを後悔する
regret to do: 残念ながら〜する
:::

`regret`も形で意味が変わる代表例です。動詞ごとの型を確認し、訳だけでなく文全体の時点と発話の目的を見ます。

:::check check-38-verb-complements-06
question: 次の文の空所に入る語は? The bus stopped ( ) passengers at the corner.
choice: B|to pick up
choice: A|pick up
answer: B
explanation: stop to do は「〜するために立ち止まる」の意味です。
:::


## 7. 目的語の形を決める手順

:::board
1. 直接目的語か、V + O + ...か
2. 前の動詞の型は何か
3. 両方なら時点・意味は何か
4. `to`は不定詞か前置詞か
:::

まず文の型を分け、次に動詞の語法、最後に文脈を確認します。`look forward to doing`のような前置詞の`to`も、直接目的語の不定詞と混同しません。

:::check check-38-verb-complements-07
question: 次の文の空所に入る語は? I regret ( ) you that your application was rejected.
choice: A|to inform
choice: B|inform
answer: A
explanation: regret to inform は「残念ながらお知らせする」という、これから述べる内容への遺憾を表します。
:::
