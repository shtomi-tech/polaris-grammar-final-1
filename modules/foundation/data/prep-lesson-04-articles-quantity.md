# 冠詞・数量詞

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

前のセクションで名詞を分類したら、その結果に合う冠詞・数量詞を選びます。まず名詞の種類と数を確認し、冠詞なら特定性、数量詞なら個数・量と多さ・少なさを見ます。

## 1. a/anは単数の可算名詞につく

:::board
a/an + 単数の可算名詞
a: 子音の音
an: 母音の音
:::

`a dog`、`an engineer`のように、一つの可算名詞を取り出すときに使います。`an hour`のように、つづりではなく最初の音で`a/an`を決めます。

:::check check-04-articles-quantity-01
question: 次の文の空所に入る語は? She wants to be ( ) engineer.
choice: A|an
choice: B|a
answer: A
explanation: engineer は母音で始まる発音なので、不定冠詞 an を使います。
:::


## 2. theは特定できる名詞につく

:::board
`I saw a dog.`
`The dog was wet.`
前の文からどれか分かる
:::

`the`は単数・複数・不可算名詞のいずれにもつきます。前に出たもの、唯一のもの、状況から特定できるものかを確認します。

:::check check-04-articles-quantity-02
question: 次の文の空所に入る語は? I bought a book yesterday. ( ) book is very interesting.
choice: B|The
choice: A|A
answer: B
explanation: すでに一度話題に出た特定の本なので the book とします。
:::


## 3. many/muchは名詞の種類で分ける

:::board
many + 複数の可算名詞
much + 不可算名詞
many books / much water
:::

`books`は個数を数えるので`many`、`water`は量として扱うので`much`です。数量詞を選ぶ前に、後ろの名詞が可算か、単数・複数かを確認します。

:::check check-04-articles-quantity-03
question: 次の文の空所に入る語は? How ( ) water do you drink every day?
choice: A|much
choice: B|many
answer: A
explanation: water は不可算名詞なので、量を尋ねる much を使います。
:::


## 4. few/littleは数と量、aの有無を見る

:::board
few + 複数可算: ほとんどない
a few + 複数可算: 少しはある
little / a little + 不可算
:::

`few students`は「ほとんどいない」、`a few students`は「少しはいる」です。`little time`と`a little time`も同じく、aの有無で評価が変わります。

:::check check-04-articles-quantity-04
question: 次の文の空所に入る語は? There is very ( ) time left.
choice: B|little
choice: A|few
answer: B
explanation: time は不可算名詞なので、少量を表す little を使います。
:::


## 5. fewerとlessは比較の形

:::board
fewer + 複数の可算名詞
less + 不可算名詞
fewer chairs / less time
:::

数えられる個数を比べるなら`fewer`、量を比べるなら`less`です。`chairs`と`time`のように、後ろの名詞の種類を見て選びます。

:::check check-04-articles-quantity-05
question: 次の文の空所に入る語は? We need ( ) chairs in this room.
choice: A|fewer
choice: B|less
answer: A
explanation: chairs は複数可算名詞なので、数が少ないことを表す fewer を使います。
:::


## 6. the＋複数・the＋形容詞は集団を指す

:::board
the Japanese = 日本人という集団
the rich = 裕福な人々
the books = 特定の本々
:::

`the + 複数名詞`は特定の集団、`the + 形容詞`はその性質を持つ人々を表します。`Books`の一般論と`the books`の特定集団を区別します。

:::check check-04-articles-quantity-06
question: 次の文の空所に入る語は? ( ) rich are not always happier than the poor.
choice: B|The
choice: A|A
answer: B
explanation: the + 形容詞 で「〜な人々」という集団を表し、複数扱いになります。The rich は「裕福な人々」です。
:::


## 7. 量と程度が重なる表現を読む

:::board
so little + 不可算名詞 + that ...
「とても少ないので…」
:::

`so little snow that ...`のように、`little`が量、`so ... that`が程度と結果を表すことがあります。まず名詞の可算性を決め、そのあと程度のまとまりを確認します。

:::check check-04-articles-quantity-07
question: 次の文の空所に入る語は? We had ( ) snow this winter that the ski resorts had to close early.
choice: A|so little
choice: B|so few
answer: A
explanation: snow は不可算名詞なので little を使い、程度から結果を導く形は so + 形容詞 + that です。
:::


## 8. quite a few・a large number ofは数量を強める慣用表現

:::board
quite a few + 複数可算名詞: かなり多くの
a large number of + 複数可算名詞: 多数の
a great deal of + 不可算名詞: 多量の
:::

`quite a few`は`a few`(少しはある)とは逆に、「かなり多くの」という意味になります。`a large number of mistakes`のように、数の多さを表す形容詞は`large`で、`number`の前に`much`や`many`は置きません。

:::check check-04-articles-quantity-08
question: 次の文の空所に入る語は? We found a ( ) number of mistakes in his paper.
choice: A|large
choice: B|much
answer: A
explanation: a large number of + 複数名詞 で「多数の」を表します。number を修飾するのは形容詞 large で、much や many を number の前に直接置くことはできません。
:::


## 9. mostとalmostは品詞が違う

:::board
most + of + 名詞: ほとんどの(代名詞・形容詞)
almost all/every + 名詞: ほとんどの(副詞)
almost + of は不可
:::

`most`は代名詞・形容詞として`most of them`のように`of`へ直接つながります。`almost`は副詞なので名詞や`of`を直接修飾できず、`almost all of them`のように`all`や`every`を挟みます。

:::check check-04-articles-quantity-09
question: 次の文の空所に入る語は? I guess ( ) of them went home.
choice: A|most
choice: B|almost
answer: A
explanation: most は代名詞として of them に直接つながります。almost は副詞なので of them を直接修飾できず、almost all of them のように all を挟む必要があります。
:::


## 教授からの課題

①名詞の可算性、②単数・複数、③特定性、④数量の意味の順に確認します。`a/an/the`と`many/much/few/little`を同じ基準で選ぼうとしないのがコツです。
