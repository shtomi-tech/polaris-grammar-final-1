# 仮定法の条件・倒置

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

発展の仮定法では、条件と結果の時点がずれたり、`if` が別の語や倒置に変わったりします。まず標準的な `if` 節へ戻し、条件の種類を確定します。

## 1. 混合仮定法は条件と結果の時計が違う

:::board
If S had + p.p.,
S would + 原形
過去の条件 → 現在の結果
:::

`If I had taken the job, I would live in London now.` は、過去の選択が現在の状態に影響する形です。条件と結果を同じ時点にそろえません。

:::check check-mood-subjunctive-conditions-01
question: 次の文の空所に入る語は? If I had taken that job offer, I ( ) in Tokyo now.
choice: A|would live
choice: B|would have lived
answer: A
explanation: If S + had + p.p., S + would + 原形 は、過去の条件と現在の結果を組み合わせるミックス仮定法。now が結果が現在の状態であることを示す。
:::


## 2. should・were to は未来の低い可能性

:::board
If S should + 原形: 万一～なら
If S were to + 原形: 仮に～なら
:::

ここでの `should` は義務ではなく、未来の可能性を控えめに示します。`were to` も現実から距離を置く未来の仮定です。

:::check check-mood-subjunctive-conditions-02
question: 次の文の空所に入る語は? If the plan were to ( ), we would need another option.
choice: B|fail
choice: A|failed
answer: B
explanation: were to + 動詞の原形 で、将来の仮の事態を表します。
:::


## 3. if を使わない条件を読み替える

:::board
without + 名詞: ～がなければ
but for + 名詞: ～がなければ
even if + 節: たとえ～でも
:::

`Without your help, I could not have finished.` のように、前置詞句が条件を含むことがあります。`even if` は条件を認めても結果が変わらない譲歩です。

:::check check-mood-subjunctive-conditions-03
question: 次の文の空所に入る語は? ( ) your help, I could not have finished the project on time.
choice: A|Without
choice: B|Unless
answer: A
explanation: without + 名詞 は「もし~がなければ」という仮定条件を表せる。主節が could not have + p.p. なので、実際にあった助力がなかったらという過去の反実仮想を表す。
:::


## 4. if の省略は倒置から元へ戻す

:::board
Had I known = If I had known
Were I you = If I were you
Should you need help = If you should need help
:::

文頭の `Had`・`Were`・`Should` と主語の入れ替わりを見たら、`if` を補います。標準形へ戻してから、現在・過去・未来の仮定を判断します。

:::check check-mood-subjunctive-conditions-04
question: 次の文の空所に入る語は? ( ) known you were in the hospital, I would have come to see you.
choice: B|Had I
choice: A|Having been
answer: B
explanation: 「知っていたなら、会いに行ったのに」という過去の反実仮想です。Had I known は If I had known の if省略倒置です。
:::


## 5. 条件を表す語と助動詞を分ける

:::board
条件の形: if / without / even if / were to
結果の形: would / could / might
:::

条件側に `would` を置くかどうか、結果側に `could` を置くかどうかは別の判断です。条件と結果を別々の欄に書きます。

:::check check-mood-subjunctive-conditions-05
question: 次の文の空所に入る語は? Even ( ) the road is crowded, we will arrive on time.
choice: A|if
choice: B|because
answer: A
explanation: even if + S + V は「たとえ〜でも」という譲歩条件を表します。ここでは「たとえ道が混んでいても、時間どおりに着く」という意味なので if が適切です。
:::


## 6. if it were not for は現在の支えを外す

:::board
If it were not for your help,
I would fail.
「あなたの助けがなければ」
:::

`if it were not for` は、現在あるものが結果を支えているという仮定を表します。`without` に近い意味ですが、節の形まで確認します。

:::check check-mood-subjunctive-conditions-06
question: 次の文の空所に入る語は? ( ) for your support, I would give up this project right now.
choice: B|If it were not
choice: A|If it is not
answer: B
explanation: 現在の事実に反する仮定を「〜がなければ」と述べる形が If it were not for ... です。前置詞句の Without your support, ... や、ifを省いた倒置形 Were it not for your support, ... も同じ内容を表します。
:::


## 7. 発展問題は標準形へ戻して解く

:::board
1. 条件を見つける
2. if を補う
3. 条件と結果の時点を分ける
4. 助動詞と完了形を照合する
:::

倒置や前置詞句が出ても、最初から特殊構文として覚え直しません。標準形へ戻せば、基本の時計で判断できます。

:::check check-mood-subjunctive-conditions-07
question: 次の文の空所に入る語は? ( ) you need further information, please contact us.
choice: A|Should
choice: B|Had
answer: A
explanation: If you should need の if を省略すると Should you need になります。
:::
