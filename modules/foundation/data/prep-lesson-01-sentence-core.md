# 文の骨格・5文型

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

英文をいきなり訳さず、まず骨格を見つけます。Vを中心にSを探し、修飾語を脇に置き、残った語がOかCかを判断します。最後にS・V・O・Cの関係から文型を決めましょう。

:::board
この単元の問い
「この語は、文の中で何をしている？」
:::

## 1. VとSを先に見つける

:::board
V = 動作・状態の中心
S = その主体
`has finished` = V全体
:::

`My sister has finished her homework.`では、Vは`has finished`全体です。Vを決めたら「誰がその動作・状態を担うか」を探します。助動詞だけ、過去分詞だけをVにしないのが出発点です。

:::check check-01
question: `My sister has finished her homework.` のV全体は？
choice: A|`finished`だけ
choice: B|`has finished`全体
answer: B
explanation: 助動詞 `has` と過去分詞 `finished` が組になって、完了の動作全体を表します。
:::

## 2. 修飾語Mをいったん外す

:::board
`The old bridge [across the river] collapsed.`
S: The old bridge
M: across the river
:::

`across the river`は橋を説明する前置詞句で、主語の中心ではありません。前置詞句や副詞を一度括弧に入れ、`The old bridge collapsed.`という骨格を確認します。情報を捨てるのではなく、最後に戻します。

:::check check-02
question: `The old bridge across the river collapsed.` でMは？
choice: A|`The old bridge`
choice: B|`across the river`
answer: B
explanation: `across the river` は橋を説明する前置詞句で、骨格のSではありません。
:::

## 3. Oは動作の対象、前置詞の後ろとは別

:::board
S + V + O: `Ken repaired the bicycle.`
O = 動作を直接受ける語
:::

`the bicycle`は修理される対象なのでOです。一方、`across the river`のような前置詞句は、後ろの名詞が動詞に直接つながるOではありません。まず前置詞の有無を確認します。

:::check check-03
question: `Ken repaired the bicycle.` の `the bicycle` は？
choice: A|動作を直接受けるO
choice: B|前置詞句M
answer: A
explanation: `repaired what?` に前置詞なしで答える対象なので、`the bicycle` はOです。
:::

## 4. CはSまたはOを説明する

:::board
SVC: `The sky became dark.`
S = C
SVOC: `The coach made the players tired.`
O = C
:::

`dark`は空の状態、`tired`は選手の状態を説明します。同じ「説明する語」でも、Sを説明すればSVC、Oを説明すればSVOCです。「誰と＝になるか」を確認します。

:::check check-04
question: `The sky became dark.` の `dark` の働きは？
choice: A|動作の対象O
choice: B|主語の状態を説明する補語C
answer: B
explanation: `dark` は `The sky` の状態を説明するのでCです。`became` の後ろでも、動作の対象ではありません。
:::

## 5. 第1文型と第3文型を分ける

:::board
SV: `The children laughed loudly.`
SVO: `Ken repaired the bicycle.`
`loudly` = M
:::

`The children laughed`だけで文が成立するので、`loudly`はMです。`repaired the bicycle`は動作の対象があるのでSVO。動詞の後ろに語があるかではなく、直接の対象かどうかで分けます。

:::check check-05
question: `The children laughed loudly.` の `loudly` は？
choice: A|動詞の対象O
choice: B|動作の様子を足すM
answer: B
explanation: `The children laughed` で文が成立し、`loudly` は動作の様子を加える副詞です。
:::

## 6. 第4文型は「受け手」と「もの」

:::board
SVOO: `She gave me a useful tip.`
1つ目のO = 受け手
2つ目のO = 与えられるもの
:::

`me`は受け手、`a useful tip`はものです。`do me a favor`も同じく「人に、ものをする」という型です。名詞が二つあるときは、誰に何をするかを確認します。

:::check check-06
question: `She gave me a useful tip.` で `me` は？
choice: A|受け手のO
choice: B|様子を表すM
answer: A
explanation: `me` は「誰に」、`a useful tip` は「何を」にあたり、前置詞なしで2つのOが続きます。
:::

## 7. 第2文型を作る動詞もある

:::board
look / remain / feel + 形容詞
`You look happy.`
S = C → SVC
:::

`look`は「〜に見える」、`remain`は「〜のままである」、`feel`は「〜と感じる」です。後ろの形容詞が主語の状態を説明していれば、第2文型です。動詞の意味だけでなく、後ろとの関係を見ます。

:::check check-07
question: `You look happy.` の `happy` は？
choice: A|主語Youを説明するC
choice: B|動作を直接受けるO
answer: A
explanation: `You = happy` の関係で、`happy` は主語を説明する補語です。
:::

## 8. 文型を決める手順

:::board
V → S → Mを脇に置く → O/C → 文型
:::

迷ったら、文を一気に訳しません。まずV、次にSを探し、前置詞句や副詞を脇に置きます。残った語が直接の対象か、S/Oの説明かを確認し、最後にMを戻します。

:::check check-08
question: 文型を決める最初の順番は？
choice: A|V→S→Mを脇に置く→O/C→文型
choice: B|日本語訳→文型→Vを探す
answer: A
explanation: まず中心語Vと主体Sを押さえ、修飾をいったん外すと残りのO/Cを判断しやすくなります。
:::
