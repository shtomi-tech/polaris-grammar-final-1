# 関係代名詞の基本

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

関係代名詞は、名詞を説明する節を作ります。先行詞だけで選ばず、節の中で置き換えられた名詞の役割を探します。

## 1. 関係代名詞は先行詞と節内の席を受ける

:::board
the book which I read
which = book / readの目的語
:::

`which`は前の名詞を受け、節の中で主語・目的語などの役割を持ちます。接続詞としてつなぐだけではないことを確認します。

:::check check-10-relatives-01
question: 次の文の空所に入る語は? The book ( ) I bought yesterday is interesting.
choice: A|which
choice: B|who
answer: A
explanation: 関係詞節内で目的語が欠けており、先行詞が物なので which が適切です。
:::


## 2. 主格と目的格を分ける

:::board
主格: the boy who lives here
目的格: the book which I bought
:::

`who lives`ではwhoがlivesの主語、`which I bought`ではwhichがboughtの目的語です。関係詞の後ろに主語があるかを見ます。

:::check check-10-relatives-02
question: 次の文の空所に入る語は? The book ( ) I bought yesterday is interesting.
choice: B|which
choice: A|who
answer: B
explanation: 関係詞節内で目的語が欠けており、先行詞が物なので which が適切です。
:::


## 3. 目的格は省略できることがある

:::board
the book (which) I bought
主格 who lives → 原則、省略しない
:::

`I bought __`のように目的語の空所を埋める関係代名詞は省略できる場合があります。主格の`who`は、単純に消すと主語がなくなるため残します。

:::check check-10-relatives-03
question: 次の文の空所に入る語は? The teacher ( ) I met yesterday was kind.
choice: A|whom
choice: B|who
answer: A
explanation: 関係詞節内で目的語が欠けており、先行詞が人なので目的格の whom が適切です。
:::


## 4. whoseは所有の関係を示す

:::board
whose + 名詞
the girl whose father is a doctor
:::

`whose father`は「その人の父」という所有関係です。whoseの後ろには名詞が続き、先行詞との持ち主の関係を作ります。

:::check check-10-relatives-04
question: 次の文の空所に入る語は? I met a girl ( ) father is a doctor.
choice: B|whose
choice: A|who
answer: B
explanation: whose father で「その父親が医師である少女」を表し、所有関係を示します。
:::


## 5. that節と関係代名詞thatを分ける

:::board
the fact that he left: 完全な文
the book that I read: readの目的語が不足
:::

同じ`that`でも、後ろが完全なら同格の接続詞、節内に主語・目的語の不足があれば関係代名詞です。前の名詞との関係も確認します。

:::check check-10-relatives-05
question: 次の文で、that の後ろが完全な文になっているものを選びなさい。
choice: A|the fact that he left
choice: B|the book that I bought
answer: A
explanation: that he left は主語 he と動詞 left がそろった完全な節で、the fact の内容を示す同格節です。
:::


## 6. 関係代名詞を選ぶ手順

:::board
先行詞 → 節内の不足 → 主格・目的格・所有 → 省略の可否
:::

関係代名詞の問題は、先行詞だけで決めません。節を短く言い直し、主語・目的語・所有のどこが必要かを確認します。

:::check check-10-relatives-06
question: 次の文の空所に入る語は? The student ( ) won the prize is my friend.
choice: B|who
choice: A|whom
answer: B
explanation: 関係詞節内で空所が主語で、先行詞が人なので主格の who を使います。
:::
