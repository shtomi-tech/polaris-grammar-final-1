# 願望・類似・提案・命令

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

願望・類似・提案・命令は、現実から距離を置く表現と、相手への働きかけを含みます。形を丸暗記せず、何を実現したい文なのかを確認します。

## 1. 命令文は主語を置かず原形で始める

:::board
Open the window.
Please wait here.
命令・依頼: 動詞の原形
:::

命令文は、相手を主語として省略し、動詞の原形で始めます。疑問文のように `do` を先に置かず、文の目的が指示か質問かを見ます。

:::check check-mood-wish-proposal-01
question: 次の文の空所に入る語は? ( ) the instructions carefully.
choice: A|Read
choice: B|Reads
answer: A
explanation: 命令文では構造上の主語 you を省略し、動詞の原形を文頭に置きます。
:::


## 2. 否定命令は Don't + 原形

:::board
Don't open the door.
「ドアを開けてはいけない」
:::

否定命令は `Do not` または `Don't + 原形` です。`not` の位置と、一般動詞を受ける `do` の形を確認します。

:::check check-mood-wish-proposal-02
question: 次の文の空所に入る語は? ( ) touch that wire.
choice: B|Don't
choice: A|Doesn't
answer: B
explanation: 否定命令文は Don't + 動詞の原形 です。
:::


## 3. 話法の命令は tell/ask + 人 + to不定詞

:::board
He told me to wait.
She asked me not to leave.
:::

命令文を間接話法にすると、`tell/ask + 人 + to不定詞` の形にします。否定命令は `not to + 原形` へ変えます。

:::check check-mood-wish-proposal-03
question: 次の文の空所に入る語は? The teacher said to us, "Be quiet." → The teacher told us ( ).
choice: A|to be quiet
choice: B|that be quiet
answer: A
explanation: 命令文を間接話法にするときは、tell/ask + 人 + to不定詞 の形にする。
:::


## 4. wish は現実と願望の時点をずらす

:::board
wish + 過去形 → 今の願い
wish + had + p.p. → 過去への後悔
:::

`I wish I were taller.` は現在の事実と反対の願い、`I wish I had studied harder.` は過去への後悔です。形の過去と意味の時点を分けます。

:::check check-mood-wish-proposal-04
question: 次の文の空所に入る語は? I wish I ( ) more free time.
choice: B|had
choice: A|have
answer: B
explanation: 現在の事実と異なる願望は wish + 過去形 で表します。
:::


## 5. if only も同じ時計を持つ

:::board
If only I were free!
If only I had known!
:::

`if only` は強い願望を表します。後ろの過去形・過去完了形から、現在の願いか過去の後悔かを判断します。

:::check check-mood-wish-proposal-05
question: 次の文の空所に入る語は? If only I ( ) a flashlight!
choice: A|had brought
choice: B|bring
answer: A
explanation: If only は「~さえしていれば」という強い願望・後悔を表します。過去の事実への後悔なので、had brought を続けます。
:::


## 6. as if は主節との前後関係で決める

:::board
as if + 過去形 → 同時の非現実
as if + had + p.p. → それより前の非現実
:::

`He talks as if he knew everything.` は今の話し方と反対の仮定、`as if he had seen it` は主節より前の出来事です。

:::check check-mood-wish-proposal-06
question: 次の文の空所に入る語は? He talks as if he ( ) the accident with his own eyes, but he was not even there.
choice: B|had seen
choice: A|saw
answer: B
explanation: as if は現実との距離を示します。主節より前の、実際には起きていない内容なら過去完了 had seen を使います。
:::


## 7. 提案の that節は原形を保つ

:::board
suggest that S + 原形
suggest that S should + 原形
:::

`I suggested that he take a rest.` の `take` は原形です。提案の内容を表す that節では、三単現の `-s` を足さない形が使われます。

:::check check-mood-wish-proposal-07
question: 次の文の空所に入る語は? The doctor suggested that he ( ) more exercise.
choice: A|get
choice: B|gets
answer: A
explanation: suggest の提案内容は that S (should) + 原形 で表す。
:::


## 8. It's time that は現在への促し

:::board
It's time (that) S + 過去形
「もう～する時間だ」
:::

`It's time that you went to bed.` は過去の出来事ではなく、現在への促しです。形の過去と意味の現在を別々に確認します。

:::check check-mood-wish-proposal-08
question: 次の文の空所に入る語は? It's time that you ( ) to bed, John.
choice: B|went
choice: A|are going
answer: B
explanation: It's time that S + 過去形 は「もうSが~する時間だ」という現在への提案です。過去の出来事を表すのではなく、距離を置いた過去形 went を使います。
:::
