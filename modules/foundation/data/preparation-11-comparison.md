# 比較の基本

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

比較では、先に「何と何を比べるか」を決めます。同じ程度・二つの差・範囲内の一番を分けると、形の選択が安定します。

## 1. 比較する対象と形を決める

:::board
同じ程度 → 原級
二つの差 → 比較級
範囲内の一番 → 最上級
:::

空所の前後だけでなく、比較される相手と範囲を探します。形を決める前に、何と何を比べているかを一言で言います。

:::check check-11-comparison-01
question: 次の文の空所に入る語は? She is one of the ( ) students in her class.
choice: A|smartest
choice: B|smart
answer: A
explanation: one of the + 最上級 + 複数名詞 の形なので smartest が適切です。
:::


## 2. 同じ程度は as ... as

:::board
as + 形容詞・副詞の原級 + as
Tom is as tall as Ken.
:::

同じ程度を比べるときは `as ... as` です。後ろの `as` の後には比較相手を置き、比較級や最上級を入れません。

:::check check-11-comparison-02
question: 次の文の空所に入る語は? No other country in the world is as ( ) as Japan.
choice: B|clean
choice: A|cleaner
answer: B
explanation: as + 原級 + as の形なので、形容詞の原級 clean を使います。No other country ... が「日本ほどきれいな国はない」という最上級相当の意味を作ります。
:::


## 3. 二つの差は比較級 + than

:::board
比較級 + than
短い語: -er
長い語: more + 形容詞・副詞
:::

`faster than`、`more useful than` のように、二つの差は比較級で表します。`more quicker` のように `more` と `-er` を重ねません。

:::check check-11-comparison-03
question: 次の文の空所に入る語は? Going by train is ( ) than driving.
choice: A|quicker
choice: B|more quicker
answer: A
explanation: than driving があるので、二つの移動方法の差を表す比較級です。短い形容詞 quick は quicker となり、more は重ねません。
:::


## 4. 範囲内の一番は the 最上級

:::board
the + 最上級 + in/of + 範囲
the tallest in the class
:::

三つ以上の範囲で一番なら `the tallest`、`the most useful` の形です。`in the class` や `of the three` が、順位を決める範囲を示します。

:::check check-11-comparison-04
question: 次の文の空所に入る語は? Of the three members, Taro was ( ) pianist.
choice: B|the best
choice: A|a best
answer: B
explanation: Of the three は三人の範囲を示すので、最上級 the best を使います。best は good の最上級で、通常 a ではなく the と結びつきます。
:::


## 5. 比較級・最上級の強め方を分ける

:::board
much / far + 比較級
by far + 最上級
very + 原級
:::

`much better` は比較級、`by far the best` は最上級を強めます。`very better` とはしないので、まず空所の形を確認します。

:::check check-11-comparison-05
question: 次の文の空所に入る語は? My new computer is faster ( ) my old one.
choice: A|than
choice: B|as
answer: A
explanation: 比較級 faster の比較対象は than で導きます。
:::


## 6. 二人のうち一方は the 比較級

:::board
the + 比較級 + of the two
Jane is the taller of the two.
:::

二人を比べて一方を特定するときは、最上級ではなく `the taller` のような比較級を使います。`of the two` が見えたらこの形を疑います。

:::check check-11-comparison-06
question: 次の文の空所に入る語は? Jane and Betty are sisters. Jane is ( ) of the two.
choice: B|the taller
choice: A|tall
answer: B
explanation: of the two は二人を比べる範囲です。二者の差を表す比較級 taller に、対象を特定する the を付けて the taller of the two とします。
:::


## 7. できるだけは as ... as possible

:::board
as + 原級 + as possible
as soon as possible
:::

`as soon as possible` は「できるだけ早く」です。`as ... as` の間には形容詞・副詞の原級を置き、`than` は使いません。

:::check check-11-comparison-07
question: 次の文の空所に入る語は? Please come as soon ( ) possible.
choice: A|as
choice: B|than
answer: A
explanation: as soon as possible は「できるだけ早く」という定型の原級比較です。
:::


## 8. 最上級相当の no other・nothing

:::board
No other + 単数名詞 + as ... as A
Nothing is more precious than time.
:::

`No other city is as large as Tokyo.` や `Nothing is more precious than time.` は、最上級を使わずに「Aほど…なものはない」と表します。否定語と比較形を一組で読みます。

:::check check-11-comparison-08
question: 次の文の空所に入る語は? Nothing is ( ) than time.
choice: B|more precious
choice: A|as precious
answer: B
explanation: than time が二つのものの差を示すので、比較級 more precious を使います。Nothing is more precious than time は「時間ほど貴重なものはない」です。
:::


## 9. 比較問題は対象・形・範囲の順で解く

:::board
1. 比較対象を囲む
2. 原級・比較級・最上級を決める
3. than / as / in / of を確認
:::

比較語だけを訳さず、対象と範囲を文に戻します。二者の差なら比較級、同程度なら原級、範囲内の一番なら最上級です。

:::check check-11-comparison-09
question: 次の文の空所に入る語は? My new computer is faster ( ) my old one.
choice: A|than
choice: B|as
answer: A
explanation: 比較級 faster の比較対象は than で導きます。
:::
