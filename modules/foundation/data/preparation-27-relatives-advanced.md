# 関係詞の応用

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

応用でも中心は「先行詞を受け、節の中でどの役割をするか」です。そこにコンマ、前置詞、複合関係詞、節全体を受けるwhichが加わります。

## 1. 非制限用法は補足情報を区切る

:::board
My brother, who lives in Osaka, is visiting us.
コンマ内 = 補足説明
:::

コンマで区切られた関係詞節は、すでに特定できる名詞への補足です。通常`that`は使わず、限定する用法と情報の働きを分けます。

:::check check-27-relatives-advanced-01
question: 次の文の空所に入る語は? My brother, ( ) lives in Osaka, is visiting us.
choice: A|who
choice: B|that
answer: A
explanation: 人を受け、コンマの後ろの非制限用法で補足説明をするため who を使います。
:::


## 2. 前置詞と関係代名詞を戻す

:::board
the person to whom I spoke
the chair on which I sat
:::

元の文を`I spoke to him`、`I sat on it`のように戻すと、前置詞の結びつきが見えます。前置詞を前へ出す形では、後ろにwhom/whichを置きます。

:::check check-27-relatives-advanced-02
question: 次の文の空所に入る語は? This is the chair on ( ) I sat.
choice: B|which
choice: A|who
answer: B
explanation: 前置詞 on の後ろなので、物を受ける目的格 which を使います。
:::


## 3. 前置詞後置と省略の可否を分ける

:::board
the job which he trained for
the book (that) I read
主格 who lives → 省略しない
:::

目的格が節内の空所になる場合は、関係代名詞を省略できることがあります。前置詞の直後や主格では同じように消しません。元の節を復元します。

:::check check-27-relatives-advanced-03
question: 関係代名詞を省略できる文を選びなさい。
choice: A|The book that I read was useful.
choice: B|The man who lives next door is kind.
answer: A
explanation: 省略できるのは、制限用法で目的格の関係代名詞のときだけです。正答の The book that I read was useful. の that は関係詞節内で read の目的語なので省略できます。
:::


## 4. where・when・whichは節の完全性で選ぶ

:::board
the moment when the lights went out
the park which we visited
:::

`the moment when ...`は節が完全で、時を補います。`which we visited`はvisitedの目的語が不足しています。先行詞の種類より、節の内部を優先します。

:::check check-27-relatives-advanced-04
question: 次の文の空所に入る語は? I still remember the moment ( ) the lights went out.
choice: B|when
choice: A|where
answer: B
explanation: 後ろの the lights went out は主語と動詞がそろった完全な節で、先行詞 the moment が表す時の副詞情報が欠けています。そのため時を表す関係副詞 when が適切です。
:::


## 5. コンマのwhichは前の節全体を受ける

:::board
Mia refused to apologize,
which surprised everyone.
which = 前の出来事全体
:::

この`which`は特定の名詞ではなく、前の節の内容を受けます。コンマの後ろで、前の出来事への結果や評価を加える形です。

:::check check-27-relatives-advanced-05
question: 次の文の空所に入る語は? Mia refused to apologize, ( ) surprised everyone at the meeting.
choice: A|which
choice: B|that
answer: A
explanation: 直前に which が受ける名詞がなく、コンマ前の Mia refused to apologize という出来事全体を受けるため、非制限用法の which を使います。
:::


## 6. 複合関係詞は節全体を作る

:::board
Whoever comes first ...
However hard you try, ...
No matter how tired we are, ...
:::

`whoever`は「〜する人は誰でも」、`however + 形容詞`は「どんなに〜でも」です。複合関係詞自身が節内の役割を持つか、後ろの語順が整っているかを見ます。

:::check check-27-relatives-advanced-06
question: 次の文の空所に入る語は? ( ) hard you try, you cannot finish this task in a day.
choice: B|However
choice: A|Whatever
answer: B
explanation: however + 形容詞/副詞 + S + Vで「どんなに〜でも」という譲歩を表します。この文では hard が動詞 try を修飾する副詞で、however はその程度を強めています。
:::


## 7. 応用関係詞は元の文へ戻す

:::board
先行詞 → 節内の不足 → コンマ/前置詞
→ 省略・複合関係詞
:::

長い文は、先行詞と関係詞節を分け、元の二文に戻します。最後にコンマが補足か、whichが前の節全体を受けるかを確認して問題を解きます。

:::check check-27-relatives-advanced-07
question: 次の文の空所に入る語は? My brother, ( ) lives in Osaka, works as an architect.
choice: A|who
choice: B|that
answer: A
explanation: コンマで挟まれた節は非制限用法であり、「(一人しかいない)兄について、補足情報を加えている」。節内では主語の働きをしているので主格を使う。
:::
