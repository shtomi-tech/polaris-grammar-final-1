# 代名詞・限定詞

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

ここでは、名詞の前に置いて限定する語と、名詞の代わりになる代名詞を分けます。まず文中の位置、次に後ろの名詞の有無と数、最後に指す範囲を確認します。

## 1. 代名詞の格は文中の位置で決まる

:::board
主語: I / he / they
目的語: me / him / them
前置詞の後ろ: for me / with him
:::

`respect for her`の`her`は前置詞`for`の目的語です。`she has taught me`の`she`は別の節の主語。まず前置詞や動詞との位置関係を見て格を決めます。

:::check check-14-pronouns-determiners-01
question: 次の文の空所に入る語は? I have great respect for ( ); she has taught me so much.
choice: A|her
choice: B|she
answer: A
explanation: 前置詞の目的語になる代名詞は目的格にする。
:::


## 2. 所有格と所有代名詞を分ける

:::board
所有格 + 名詞: my book / their idea
所有代名詞: mine / yours / theirs
:::

`my`は後ろの名詞を限定し、`yours`は「あなたのもの」と名詞の代わりをします。空所の後ろに名詞があるかを確認して、形を選びます。

:::check check-14-pronouns-determiners-02
question: 次の文の空所に入る語は? This is not my notebook. Is it ( )?
choice: B|yours
choice: A|your
answer: B
explanation: 名詞を伴わず「あなたのもの」と単独で使うので、所有代名詞 yours を使います。
:::


## 3. anotherとotherは後ろの名詞を見る

:::board
another + 単数名詞: もう一つの
other + 複数名詞: ほかの
others: 名詞なしの複数
:::

`another piece`は不特定のもう一つ、`other people`はほかの人々です。`others`は後ろの名詞を置かずに「ほかの人々・もの」を受けます。

:::check check-14-pronouns-determiners-03
question: 次の文の空所に入る語は? I need ( ) pen because this one does not work.
choice: A|another
choice: B|other
answer: A
explanation: another + 単数名詞 で「もう一つのペン」を表します。
:::


## 4. the otherとthe othersは残りを特定する

:::board
二つのうち残り一つ: the other
特定された残り全部: the others
名詞つき: the other + 複数名詞
:::

`One is black, and the other is blue.`は二つのうち残り一つです。`I kept the others.`は特定された残り全部。`another`の不特定の追加と区別します。

:::check check-14-pronouns-determiners-04
question: 次の文の空所に入る語は? I have five pens. I gave one to my friend, and I kept ( ) for myself.
choice: B|the others
choice: A|others
answer: B
explanation: 全体(5本)から一部(1本)を除いた残り全部(4本、複数)を特定して指すときは the others を使う。
:::


## 5. oneとnoneは名詞の受け方が違う

:::board
one = 1つ・1人
none of + 複数名詞 = どれも・誰も〜ない
:::

`Do you have one?`の`one`は単数名詞の代わりです。`none of them`はまとまりの中に一つもないことを表します。指す範囲と数を確認します。

:::check check-14-pronouns-determiners-05
question: 次の文の空所に入る語は? You can borrow a pen if you need ( ).
choice: A|one
choice: B|this
answer: A
explanation: one は、すでに出た可算名詞の単数 a pen を繰り返さずに受ける代名詞です。「必要なら一本貸せます」となります。
:::


## 6. each otherは相互、themselvesは自分自身

:::board
They helped each other.
「お互いを」
They helped themselves.
「自分たち自身を」
:::

二人以上が互いに向かう関係なら`each other`、主語自身に戻るなら再帰代名詞です。動作の向きを確認して選びます。

:::check check-14-pronouns-determiners-06
question: 次の文の空所に入る語は? After the long debate, the two committee members finally apologized to ( ) and shook hands.
choice: B|each other
choice: A|themselves
answer: B
explanation: 2人がお互いに謝罪した(相互の関係)ので相互代名詞each otherを使う。
:::


## 7. that/thoseは名詞の繰り返しを避ける

:::board
that of + 単数名詞
those of + 複数名詞
that/those = 前の名詞の代用
:::

`The climate of this region is milder than that of the north.`では、`that`が単数の`climate`を受けます。複数の`rules`なら`those`。何を代用しているかと数を戻します。

:::check check-14-pronouns-determiners-07
question: 次の文の空所に入る語は? The climate of this region is milder than ( ) of the north.
choice: A|that
choice: B|this
answer: A
explanation: 直前のthe climateという単数名詞をof the northを伴って指し直すのでthat ofを使う。
:::


## 教授からの課題

①空所の位置、②後ろの名詞の有無と数、③不特定の追加か特定された残りか、④指す相手との関係、の順に確認します。最後に格や所有の形が文に合うかを見てください。
