# 仮定法の基本

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

仮定法は、現実から距離を置いた条件と結果を表します。まず「現実にはどうか」と「条件・結果はいつか」を確認し、その後で形を選びます。

## 1. 現在の反実仮想は過去形

:::board
If + 過去形,
S would/could/might + 原形
If I had more time, I would read more.
:::

今は時間が十分でない、というように現在の事実と反対なら、`if` 節は過去形、主節は `would/could/might + 原形` です。形の過去は、現実との距離を示します。

## 2. 現在の be動詞は were を基本にする

:::board
If I were you, I would apologize.
現在の反実仮想 → were
:::

`If I were you` は「私があなたなら」。主語が I でも、反実仮想の条件節では `were` を基本にします。通常の過去 `I was` と働きを分けます。

## 3. 過去の反実仮想は過去完了

:::board
If + had + p.p.,
S would have + p.p.
:::

実際には勉強せず、合格しなかった過去を振り返るなら、条件は `had studied`、結果は `would have passed` です。過去の条件と過去の結果を同じ時間線に置きます。

## 4. 条件節と主節の時点を別々に見る

:::board
現在の反実仮想:
過去形 → would + 原形
過去の反実仮想:
had + p.p. → would have + p.p.
:::

`would` があるから未来、`if` 節が過去形だから過去、と単語一つで決めません。条件の時点と結果の時点をそれぞれ確認します。

## 5. would・could・might は結果の意味を分ける

:::board
would: そうなるだろう
could: 可能・能力があるだろう
might: かもしれない
:::

条件の形が同じでも、結果の助動詞で意味が変わります。`If I had enough money, I could buy ...` のように、結果が能力・可能性なら `could/might` も使います。

## 6. 基本問題は現実と二本の時間線で解く

:::board
1. 現実にはどうか
2. 条件の時点
3. 結果の時点
4. if節と主節の形
:::

仮定法では条件と結果を一つの箱に入れません。現実の事実を言い直し、現在か過去かを決めてから、二つの節の形を選びます。
