# 受動態の基本

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

受動態では、動作を受けるものを主語にします。能動文の目的語を前へ移し、be動詞で時制を示し、過去分詞を続けるのが基本です。

## 1. 受動態の骨格を固定する

:::board
S + be + 過去分詞
The window was broken.
:::

be動詞が時制、過去分詞が受ける動作を示します。`was broken`全体を受動態の述語として見て、beだけ・過去分詞だけで判断しません。

:::check check-04-voice-01
question: 次の文が表す文法形式として最も適切なものを選びなさい。 The window was broken by the ball.
choice: A|受動態
choice: B|現在完了
answer: A
explanation: was + 過去分詞 broken で受動態を作っています。by the ball は行為者を示します。
:::


## 2. 能動文の目的語を主語へ移す

:::board
The chef cooked the meal.
→ The meal was cooked by the chef.
:::

能動文の目的語`the meal`が受動文の主語になります。動作主`the chef`は重要なら`by`以下に残します。視点がどこへ移ったかを確認します。

:::check check-04-voice-02
question: 次の能動態を受動態にした文として最も適切なものを選びなさい。 The chef cooked the meal.
choice: B|The meal was cooked by the chef.
choice: A|The meal cooked the chef.
answer: B
explanation: 目的語 the meal を主語にし、過去形に対応する was + cooked とします。
:::


## 3. 受動態にできるのは目的語を取る動詞

:::board
They built the bridge. → 受動態にできる
He arrived at the station. → そのままでは移せない
:::

目的語を取る他動詞なら、その目的語を主語に移せます。`at the station`は前置詞句なので、`arrive`の直接目的語ではありません。

:::check check-04-voice-03
question: 次の能動態を受動態にしたとき、主語になる語を選びなさい。 The committee selected Maria for the prize.
choice: A|Maria
choice: B|The committee
answer: A
explanation: 受動態では、能動態の直接目的語 Maria を主語にして Maria was selected ... とします。
:::


## 4. 時制はbe動詞で表す

:::board
現在: is/are employed
過去: was/were killed
未来: will be built
:::

過去分詞`built`や`killed`を変えて時制を示すのではなく、be動詞の形を変えます。主語の数と時制を同時に確認します。

:::check check-04-voice-04
question: 次の文の空所に入る語は? This building ( ) in 1900.
choice: B|was built
choice: A|built
answer: B
explanation: 1900年の過去の出来事なので過去形のbe動詞 was と過去分詞 built を使います。
:::


## 5. 助動詞付き受動態はbeを原形にする

:::board
must be done
will be built
must be finished
:::

助動詞の後ろは原形なので、受動態でも`must be finished`のように`be`を置きます。`must is finished`や`can finished`にはしません。

:::check check-04-voice-05
question: 次の文の空所に入る語は? This work must ( ) by next Wednesday.
choice: A|be done
choice: B|be doing
answer: A
explanation: must の後ろは動詞の原形です。受動態の be + 過去分詞 を続けるので、must be done となります。by next Wednesday は期限を示します。
:::


## 6. 疑問文でもbe + 過去分詞を保つ

:::board
Is Italian taught here?
Who was this picture painted by?
:::

疑問文ではbe動詞を主語の前へ出しますが、受動態の`be + 過去分詞`は崩しません。行為者を尋ねるときは文末の`by`も残ります。

:::check check-04-voice-06
question: 次の文の空所に入る語は? Who was this picture ( ) by?
choice: B|painted
choice: A|be painted
answer: B
explanation: 受動態の疑問文は be + 過去分詞 を保つので、was painted になります。行為者を表す by は文末に残ります。
:::


## 7. 受動態を解く手順

:::board
目的語 → 受動文の主語
beの時制・数 → 過去分詞 → byの要否
:::

能動文なら何が動作を受けるかを探し、その語を主語にします。次にbeの時制と数、過去分詞、最後に動作主の必要性を確認して問題を解きます。

:::check check-04-voice-07
question: 次の文の空所に入る語は? This building ( ) in 1900.
choice: A|was built
choice: B|built
answer: A
explanation: 1900年の過去の出来事なので過去形のbe動詞 was と過去分詞 built を使います。
:::


## 8. rise（自動詞）とraise（他動詞）を区別する

:::board
rise: 自動詞「上がる」目的語を取らない → 受動態にならない
raise: 他動詞「~を上げる」目的語を取る → 受動態になれる
The sun rises. / The flag is raised.
:::

受動態にできるのは目的語を取る他動詞だけです。`rise`は「(自ら)上がる」という自動詞で目的語を取らないため受動態になれません。一方`raise`は「~を上げる」という他動詞なので、`is raised`のように受動態にできます。形が似ているので、まず自動詞か他動詞かを確認します。

:::check check-04-voice-08
question: 次の文の空所に入る語は? Prices have ( ) sharply this year.
choice: A|risen
choice: B|raised
answer: A
explanation: rise は自動詞「上がる」なので、目的語を取らずに risen という形で使います。raise は他動詞で「~を上げる」という意味なので、ここでは主語 Prices が「上げる」側になってしまい合いません。
:::
