# 関係副詞の基本

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

関係副詞は、場所・時・理由を表す名詞を説明する節を作ります。先行詞だけで決めず、後ろの節が完全かを確認します。

## 1. whereは場所の副詞情報を加える

:::board
where + 完全な文: 場所
the town where I live
:::

`I live`は主語と動詞がそろった完全な節です。「その町で」という場所の情報を加えるため、場所の関係副詞`where`を使います。

:::check check-39-relative-adverbs-01
question: 次の文の空所に入る語は? Leslie grew up in the town ( ) my aunt lives.
choice: A|where
choice: B|that
answer: A
explanation: my aunt lives は目的語を必要としない完全な節で、先行詞は場所です。場所を補う関係副詞 where を使います。
:::


## 2. whenは時の副詞情報を加える

:::board
when + 完全な文: 時
the day when we first met
:::

`we first met`は文として完成しています。「その日に」という時の情報を加えるため、時の関係副詞`when`を使います。

:::check check-39-relative-adverbs-02
question: 次の文の空所に入る語は? Do you remember the day ( ) we first met?
choice: B|when
choice: A|where
answer: B
explanation: 先行詞が時 the day なので、時を表す関係副詞 when が適切です。
:::


## 3. reasonにはwhyを使うことがある

:::board
the reason why she was absent
why = 理由の副詞情報
:::

`she was absent`は完全な節です。先行詞`the reason`を受けて理由を表す関係副詞`why`を置きます。ここでは、選択肢の接続詞`because`とは役割を区別します。

:::check check-39-relative-adverbs-03
question: 次の文の空所に入る語は? I know the reason ( ) she was absent.
choice: A|why
choice: B|because
answer: A
explanation: the reason why で「彼女が欠席した理由」を表します。後ろの節は完全です。
:::


## 4. 場所の先行詞だけでwhereを決めない

:::board
the house which I visited
the house where I lived
:::

`I visited __`は目的語が不足しているので、関係代名詞`which`を使います。一方、`I lived`は完全なので、場所の副詞情報を表す`where`が候補です。

:::check check-39-relative-adverbs-04
question: 次の文の空所に入る語は? This is the house ( ) I was born.
choice: B|where
choice: A|which
answer: B
explanation: 先行詞が場所 the house で、節内に「そこで」という副詞情報が必要なので where を使います。
:::


## 5. 関係副詞を選ぶ手順

:::board
先行詞 → 節の完全性 → 欠けた副詞情報 → where・when・why
:::

まず先行詞が場所・時・理由のどれかを見ます。次に節を短く言い直し、主語や目的語ではなく場所・時・理由の情報が欠けているときに関係副詞を選びます。

:::check check-39-relative-adverbs-05
question: 次の文の空所に入る語は? This is the house ( ) my grandfather built with his own hands.
choice: A|which
choice: B|where
answer: A
explanation: 節内の built は他動詞で、その目的語(何を建てたか)が欠けている。名詞が欠けている場合は関係副詞ではなく関係代名詞を使う。
:::
