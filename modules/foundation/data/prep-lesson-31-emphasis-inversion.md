# 強調・倒置・否定の慣用

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

この単元では、肯定を強める `do` と、文頭の否定・制限語による倒置を扱います。まず普通の語順に戻し、助動詞と主語の位置を確認します。

## 1. 強調の do は肯定文を強める

:::board
do / does / did + 動詞の原形
I do understand.
:::

`I do understand your concern.` は否定ではなく「本当に理解している」です。時制や三単現の情報は `do` 側に置き、後ろの動詞は原形にします。

:::check check-31-emphasis-inversion-01
question: 次の文の空所に入る語は? I do ( ) your concern.
choice: A|understand
choice: B|understands
answer: A
explanation: 強調の do の後ろには動詞の原形を置きます。
:::


## 2. 否定・制限語を前に出すと倒置する

:::board
Never / Rarely / Hardly ...
助動詞 + 主語 + 動詞
助動詞がなければ do を補う
:::

`Rarely do I get a headache.` のように、否定に近い副詞を文頭に置くと助動詞が主語の前へ出ます。一般動詞なら `do/does/did` を補います。

:::check check-31-emphasis-inversion-02
question: 次の文の空所に入る語は? Rarely ( ) a headache, but I've had a bad one for a few days.
choice: B|do I get
choice: A|have I get
answer: B
explanation: 文頭の Rarely が否定的な頻度を表すため、一般動詞 get の疑問文型を借りて do I get と倒置します。
:::


## 3. not until・only after は主節を倒置する

:::board
Not until midnight did he finish.
Only after the test did I relax.
:::

`Not until` や `Only after` が文頭に出たら、倒置するのは主節です。一般動詞の過去なら `did + 主語 + 原形` に戻します。

:::check check-31-emphasis-inversion-03
question: 次の文の空所に入る語は? Only after the meeting ( ) the truth.
choice: A|did I understand
choice: B|I understood
answer: A
explanation: Only after ... が文頭に出ると、助動詞 did を主語の前に置き、後ろは原形 understand です。
:::


## 4. hardly・no sooner の組合せを固定する

:::board
Hardly had S + 過去分詞 when ...
No sooner had S + 過去分詞 than ...
:::

`hardly ... when`、`no sooner ... than` は対応する接続語が決まっています。前半は過去完了にし、二つの出来事の順序も確認します。

:::check check-31-emphasis-inversion-04
question: 次の文の空所に入る語は? No sooner ( ) started than the captain was taken ill.
choice: B|had the game
choice: A|the game had
answer: B
explanation: No soonerが文頭に出ると倒置が起こり、前半は過去完了had + 過去分詞にする。
:::


## 5. cannot ... too は限度のなさを表す

:::board
cannot + 動詞 + too + 形容詞・副詞
You cannot be too careful.
:::

`You cannot be too careful.` は「どんなに注意してもしすぎることはない」です。禁止や `too ... to` として読まず、`cannot ... too` を一組で訳します。

:::check check-31-emphasis-inversion-05
question: 次の文の空所に入る語は? You ( ) be too careful when you handle chemicals in the lab.
choice: A|cannot
choice: B|must
answer: A
explanation: cannot ... too ~で「どんなに〜してもし過ぎることはない」という限度のなさを表す。
:::


## 6. 倒置文を普通の語順に戻す

:::board
1. 文頭の否定・制限語を囲む
2. be / 助動詞 / do を探す
3. 主語 + 動詞に戻す
4. 慣用の接続語を照合
:::

`did he finish` を `he finished` に戻すと、何が前へ出たため倒置したかが見えます。強調構文や形式主語の `it` は特殊構文の単元で扱います。

:::check check-31-emphasis-inversion-06
question: 次の文の空所に入る語は? Only after the meeting ( ) the manager explain the new policy in detail.
choice: B|did
choice: A|does
answer: B
explanation: only + 副詞句 を強調して文頭に置くと、後ろは疑問文と同じ語順に倒置する。述語動詞が裸の一般動詞(過去)なので did を補って倒置する。
:::


## 7. still less/much lessは限度を表す否定の慣用

:::board
否定文, still less/much less + (S+V省略)
「まして〜ない」
:::

`cannot ... too`と同じく、否定の程度を表す慣用表現です。`I don't want my mother to find out, still less my father.`は「母に知られたくない、まして父になど知られたくない」という意味で、前の否定をさらに強く打ち消す対象をあとから追加します。

:::check check-31-emphasis-inversion-07
question: 次の文の空所に入る語は? I don't want my mother to find out about my boyfriend, ( ) my father.
choice: A|still less
choice: B|even more
answer: A
explanation: 否定文のあとで「まして〜ない」と、さらに程度の強いことを打ち消すのは still less です。
:::
