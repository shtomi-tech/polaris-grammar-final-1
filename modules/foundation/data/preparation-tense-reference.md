# 基準時と単純形

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

時制は、出来事をいつの時計から見るかを決める仕組みです。まず基準時を置き、次に出来事の種類を決めます。ここでは現在形と過去形を中心に、文の土台をそろえます。

## 1. 現在形は現在の事実をまとめる

:::board
習慣: I visit the library every Saturday.
事実: Water boils at 100°C.
状態: I know the answer.
:::

現在形は「今この瞬間」だけでなく、習慣・一般的事実・状態を表します。`know` のような状態動詞は、動作の途中を表す進行形にしにくい語です。

:::check check-tense-reference-01
question: 次の文の空所に入る語は? I ( ) the library every Saturday.
choice: A|visit
choice: B|am visiting
answer: A
explanation: every Saturday が繰り返す習慣を示すため、一般現在形 visit を使います。
:::


## 2. 過去形は過去の出来事を切り出す

:::board
I left my job and started a store.
過去の時点で完結した出来事
:::

過去の出来事を順に述べるときは過去形でそろえます。`yesterday` や `when I was ...` のような時間の手がかりが、基準時を過去へ動かします。

:::check check-tense-reference-02
question: 次の文の空所に入る語は? I ( ) to the basketball club when I was in high school.
choice: B|belonged
choice: A|belong
answer: B
explanation: when I was in high school が過去の時期を示すので、過去の所属を表す belonged を使います。belong は状態を表すため、通常進行形にはしません。
:::


## 3. be動詞と一般動詞の形を分ける

:::board
現在: am / is / are, visit / visits
過去: was / were, visited
:::

be動詞と一般動詞は、時制の変化の仕方が違います。空所の前後を見て、be動詞が必要なのか、一般動詞の形を変えるのかを先に決めます。

:::check check-tense-reference-03
question: 次の文の空所に入る語は? It ( ) sunny on that day.
choice: A|was
choice: B|is
answer: A
explanation: on that day は過去の特定の日を示します。主語 It は3人称・単数なので、be動詞の過去形は was です。
:::


## 4. 三人称単数現在には -s が要る

:::board
I/you/we/they visit
he/she/it visits
:::

現在形の一般動詞では、主語が三人称単数なら `-s` が必要です。主語が長くても、動詞と直接結びつく中心語を見ます。

:::check check-tense-reference-04
question: 次の文の空所に入る語は? Water ( ) at 100 degrees Celsius at sea level.
choice: B|boils
choice: A|is boiling
answer: B
explanation: 一般的事実(自然科学的な性質)は、一回的な動作ではなく現在形で表す。
:::


## 5. 時間の手がかりを基準時に結びつける

:::board
every day → 習慣・現在形
yesterday → 完結した過去
when I was ... → 過去の基準時
:::

時間を表す語だけで即決せず、文全体が習慣なのか一度の出来事なのかを確認します。時刻表や普遍的事実は、未来の内容でも現在形になることがあります。

:::check check-tense-reference-05
question: 次の文の空所に入る語は? I ( ) the library every Saturday.
choice: A|visit
choice: B|am visiting
answer: A
explanation: every Saturday が繰り返す習慣を示すため、一般現在形 visit を使います。
:::


## 6. 現在形でも確定した未来を表す

:::board
The train leaves at 6:45 tomorrow.
時刻表・運行表による確定予定
:::

時刻表や公式の日程のように、個人の意志では変わりにくい予定は現在形で表します。未来の内容でも、基準となる予定表は現在の事実です。

:::check check-tense-reference-06
question: 次の文の空所に入る語は? According to the schedule, the train ( ) Tokyo Station at 6:45 tomorrow morning.
choice: A|leaves
choice: B|is leaving
answer: A
explanation: 個人の予定(進行形)や単なる予測(will)とは異なり、時刻表など確定したダイヤに基づく未来の出来事は現在形で表します。
:::


## 7. 単純形の問題は五段階で解く

:::board
1. 基準時を探す
2. 習慣・事実・状態か、過去の出来事か決める
3. be動詞か一般動詞か分ける
4. 主語の数を確認する
5. 選択肢の形を照合する
:::

時制を先に、語尾を後に確認します。いきなり `-s` だけを探すと、時間の判断を置き忘れます。文法問題は時々、順番を見ています。

:::check check-tense-reference-07
question: 次の文の空所に入る語は? My father ( ) on a business trip three days ago.
choice: B|went
choice: A|goes
answer: B
explanation: three days ago は過去の時点をはっきり示すので、単純過去の went を使います。現在完了や過去完了ではなく、過去の出来事として扱います。
:::
