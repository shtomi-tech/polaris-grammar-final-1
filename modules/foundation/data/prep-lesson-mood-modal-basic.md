# 助動詞と基本的な態度

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

Mood は、出来事そのものではなく、話し手がそれをどう見ているかを示します。助動詞はその入口です。まず `助動詞 + 原形` の骨格を取り、次に可能・許可・義務・予測を選びます。

## 1. 助動詞の後ろは原形

:::board
can go / may go / must go / should go
助動詞 + 動詞の原形
:::

助動詞の後ろでは、三単現の `-s` や `to` を足しません。主語が三人称単数でも、助動詞が時制と態度を受け持ちます。

:::check check-mood-modal-basic-01
question: 次の文の空所に入る語は? She can ( ) very fast.
choice: A|run
choice: B|runs
answer: A
explanation: 助動詞 can の後ろには動詞の原形を置くため、run が適切です。主語が She でも、can の後ろに三単現の -s は付けません。
:::


## 2. can は能力・可能・許可を表す

:::board
I can swim.（能力）
It can be dangerous.（一般的可能性）
Can I leave?（許可）
:::

`can` の共通点は「可能」です。誰の能力か、一般に起こりうることか、相手に許可を求めているかを文脈で分けます。

:::check check-mood-modal-basic-02
question: 次の文の空所に入る語は? Even experienced drivers ( ) make mistakes sometimes.
choice: B|can
choice: A|must
answer: B
explanation: can は「ありえる」という一般的な可能性を表す。「経験豊富な運転手でも」という譲歩の文脈と合う。
:::


## 3. may は許可と可能性を表す

:::board
You may leave now.（許可）
It may rain tonight.（可能性）
:::

`may` も、許可と可能性の両方を表します。主語の能力ではなく、外から見た許可や、起こるかもしれないという判断です。

:::check check-mood-modal-basic-03
question: 次の文の空所に入る語は? It ( ) snow tomorrow, but the forecast isn't certain yet.
choice: A|may
choice: B|must
answer: A
explanation: may は「半々」程度の確信度の推量を表す。「予報がまだ確実でない」という文脈がこれに合う。
:::


## 4. must と have to は義務を作る

:::board
must + 原形
have to + 原形
義務・必要
:::

`must` は話し手の強い判断、`have to` は規則や状況による必要を表しやすい形です。入試では、意味の出どころと否定形を確認します。

:::check check-mood-modal-basic-04
question: 次の文の空所に入る語は? The museum is closed today, so we ( ) come back tomorrow.
choice: A|have to
choice: B|may
answer: A
explanation: 美術館が今日閉まっているという外部の事情による必要なので、have to + 原形 が適切です。
:::


## 5. 否定は意味の向きを確認する

:::board
must not → してはいけない
do not have to → する必要はない
:::

`must not` は禁止、`do not have to` は不要です。否定が義務にかかるのか、必要性にかかるのかを言い換えて確認します。

:::check check-mood-modal-basic-05
question: 次の文の空所に入る語は? There are no rules on clothing in our office, so you ( ) wear a tie.
choice: A|don't have to
choice: B|cannot
answer: A
explanation: 服装の規則がないので、ネクタイを着ける義務はありません。don't have to + 原形 は「～する必要はない」を表します。
:::


## 6. should は助言・当然を表す

:::board
You should see a doctor.
「～したほうがよい」「～するのが当然だ」
:::

`should` は強制より弱い助言や、基準から見た当然さを表します。義務の `must` と、可能性の `may` を混ぜないようにします。

:::check check-mood-modal-basic-06
question: 次の文の空所に入る語は? You look tired. You ( ) take a rest.
choice: B|should
choice: A|shall
answer: B
explanation: should + 動詞の原形 は助言を表します。
:::


## 7. will は未来だけでなく判断を表す

:::board
It will rain.（予測）
I will help you.（意志）
The train leaves at six.（時刻表）
:::

未来の内容でも、予測・意志・確定した予定で形の役割が違います。時制の章で扱った予定表と、話し手の判断を切り分けます。

:::check check-mood-modal-basic-07
question: 次の文の空所に入る語は? The Paralympic Games ( ) in just one month.
choice: A|will begin
choice: B|began
answer: A
explanation: in just one month は現在より先の時点を示します。未来の出来事を表す will + 動詞の原形 の will begin が適切です。
:::


## 8. used toは過去の状態・習慣を表す

:::board
used to + 原形: 以前は〜していた(今はしていない)
I used to live in Osaka.
:::

`used to + 動詞の原形`は「以前は~していた(今はもう違う)」という、過去の習慣や状態と現在の対比を表します。義務を表す`should`・`ought to`や、単なる過去の予想を表す`would`とは意味が違うので混同しません。

:::check check-mood-modal-basic-08
question: 次の文の空所に入る語は? This town ( ) a small village, but now it is a big city.
choice: A|used to be
choice: B|should be
answer: A
explanation: used to be は「以前は~だった(今は違う)」という過去の状態を表します。should be は当然・義務の意味であり、過去と現在の対比を表す文脈と合いません。
:::


## 教授からの課題

助動詞を見つけたら、後ろを原形に戻し、話し手の態度を「可能・許可・義務・助言・予測」のどれかで説明してから解きます。
