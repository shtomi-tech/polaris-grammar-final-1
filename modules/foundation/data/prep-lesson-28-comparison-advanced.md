# 比較構文・数量比較

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

発展比較では、基本の比較形に倍数・数量・限度の意味が加わります。まず基本の比較対象を復元し、その後で数直線上の範囲と構文全体を読みます。

## 1. 発展問題も比較の骨格から始める

:::board
比較級: 二つの対象
最上級: 範囲内の一つ
than / in / of を確認
:::

発展問題でも、`the shortest of the three` のように基本形を先に復元します。見慣れない語があっても、対象・形・範囲の順は変わりません。

:::check check-28-comparison-advanced-01
question: 次の文の空所に入る語は? Of the three routes, the mountain path is the ( ).
choice: A|longest
choice: B|longer
answer: A
explanation: 比較する対象が3つあるので、集団内で最も長いことを表す最上級 the longest を使います。longer は二つの対象の差、long は比較を示さない形です。
:::


## 2. 倍数は 倍数 + as ... as

:::board
twice as large as A
three times as long as A
:::

`twice as large as that room` は「その部屋の二倍の広さ」です。倍数を比較級に直接つなげず、`倍数 + as ... as` を一組で確認します。

:::check check-28-comparison-advanced-02
question: 次の文の空所に入る語は? This lake is twice ( ) as that one.
choice: B|as large
choice: A|large as
answer: B
explanation: 倍数は 倍数 + as + 原級 + as の形で表す。
:::


## 3. the 比較級, the 比較級は比例関係

:::board
The more you practice,
the better you become.
～すればするほど、ますます～
:::

二つの `the + 比較級` が「～すればするほど…」を作ります。ここでの `the` は最上級の the ではなく、二つの節を対応させる構文の一部です。

:::check check-28-comparison-advanced-03
question: 次の文の空所に入る語は? The more you practice, the ( ) you become.
choice: A|better
choice: B|good
answer: A
explanation: the + 比較級, the + 比較級 の構文で、「練習すればするほど上達する」を表します。
:::


## 4. fewer・less は名詞の種類を見る

:::board
fewer + 複数可算名詞
less + 不可算名詞
few: ほとんどない
a few: 少しある
:::

`fewer mistakes` は個数、`less time` は量を比べます。`few` と `a few` は、少なさを否定的に見るか、少しあると見るかが異なります。

:::check check-28-comparison-advanced-04
question: 次の文の空所に入る語は? I have ( ) time than you do this week.
choice: B|less
choice: A|fewer
answer: B
explanation: time は不可算名詞なので、比較級には less を使う。
:::


## 5. 数量比較は限度を数直線に置く

:::board
not less than 10: 10以上
not more than 10: 10以下
as many/much as: 同じ数・量
:::

`not less than` は下限、`not more than` は上限です。`not` を単純な全否定にせず、数直線のどちら側を含むかに言い換えます。

:::check check-28-comparison-advanced-05
question: 次の文の空所に入る語は? Under the museum's safety rule, visitors must be ( ) 120 centimeters tall to enter the climbing area.
choice: A|not less than
choice: B|less than
answer: A
explanation: not less than + 数量 は、規則や基準が示す「少なくとも~」という客観的な下限を表します。この規則は身長が120センチメートル未満では入場できないことを示すので、not less than が適切です。
:::


## 6. so ... a 名詞 と such a 名詞

:::board
so + 形容詞 + a/an + 名詞
such + a/an + 形容詞 + 名詞
:::

`so difficult a problem` と `such a difficult problem` は同じ内容です。`so` は形容詞、`such` は `a/an + 形容詞 + 名詞` のまとまりを修飾します。

:::check check-28-comparison-advanced-06
question: 次の文の空所に入る語は? Ms. Mitsui is ( ) nice a person that every student respects her.
choice: B|so
choice: A|such
answer: B
explanation: so + 形容詞 + a/an + 名詞 + that ... という形なので、so nice a person that ... とします。
:::


## 7. 慣用比較は構文全体を訳す

:::board
not so much A as B: AというよりB
A is no more B than C is D
:::

`not so much A as B` は焦点を A から B へ移します。`no more ... than ...` は二つの否定を対応させる構文なので、比較級だけを単語訳しません。

:::check check-28-comparison-advanced-07
question: 次の文の空所に入る語は? A whale is no ( ) a fish than a horse is.
choice: A|more
choice: B|less
answer: A
explanation: no more A than B(くじらの構文)は「BがCでないのと同様、AもBではない」という意味。この文は「馬が魚でないのと同様、クジラも魚ではない」ことを表す。
:::


## 8. all the 比較級は程度を強める

:::board
all the better for ～
～のおかげでいっそうよい
:::

`all the better for the experience` の `all` は「すべて」ではなく、`better` の程度を強めます。比較級の前後をまとめて意味にします。

:::check check-28-comparison-advanced-08
question: 次の文の空所に入る語は? I like him all the ( ) for his faults.
choice: B|better
choice: A|best
answer: B
explanation: all the better for ... は「~があるからなおさらよい」という比較級を使った慣用表現です。for his faults は理由を示します。
:::


## 9. 発展比較は基準・方向・範囲を復元する

:::board
1. 基準は何か
2. 数・量の上限下限はどちらか
3. 比較構文全体が何を言うか
:::

倍数や `not` がある文は、空所の語だけで判断しません。基準を一つ置き、差の方向と範囲を言い直してから選択肢を比べます。

:::check check-28-comparison-advanced-09
question: 次の文の空所に入る語は? The problem was less difficult ( ) I had expected.
choice: A|than
choice: B|as
answer: A
explanation: less + 形容詞 + than で「〜ほど難しくない」を表します。
:::
