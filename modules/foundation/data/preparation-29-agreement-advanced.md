# 複合主語・数量・相関接続の一致

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

基本単元では、近くの名詞に引っぱられず、主語の中心語を探しました。ここでは、その中心語を決めたあと、数量表現・相関接続・`so/neither` がどの語に一致するかを確認します。

## 1. 前置詞句を外して中心語を見る

:::board
The cat with two kittens is sleeping.
中心: cat
with two kittens = 修飾語
:::

`with two kittens` が複数でも、主語の中心は単数の `cat` です。主語を `The cat ...` と短く言い直し、動詞を `is sleeping` に合わせます。近い名詞より中心語を先に確定します。

:::check check-29-agreement-advanced-01
question: 次の文の空所に入る語は? The cat with two kittens ( ) sleeping on the sofa.
choice: A|is
choice: B|are
answer: A
explanation: 主語の中心は単数の cat です。with two kittens は cat を説明する前置詞句なので、複数の kittens に動詞を合わせず is sleeping とします。
:::


## 2. each/every/one of は単数の中心を作る

:::board
each/every student has
each of them is
one of the students is
:::

`each`・`every`・`one` は一人ずつ、または一人を示す中心なので単数扱いです。`of them`・`of the students` は範囲の説明で、後ろの複数語に動詞を合わせません。

:::check check-29-agreement-advanced-02
question: 次の文の空所に入る語は? One of the students in this class ( ) absent today.
choice: B|is
choice: A|are
answer: B
explanation: 主語の核はoneなので、動詞は単数形にする。of the studentsは修飾語句であり一致には影響しない。
:::


## 3. so/neither は前の文の形を受ける

:::board
Susan likes chocolate, and so does Hiroshi.
My sister didn't play, and neither did I.
so/neither + 助動詞 + 主語
:::

肯定内容なら `so`、否定内容なら `neither` を使います。前半が現在の一般動詞なら `do/does`、過去なら `did`。後ろの主語の人称・数も確認し、前の動詞をそのまま繰り返しません。

:::check check-29-agreement-advanced-03
question: 次の文の空所に入る語は? Susan likes chocolate and so ( ) Hiroshi.
choice: A|does
choice: B|do
answer: A
explanation: 前半が一般動詞の現在形 likes で、主語 Hiroshi は三人称単数です。内容を受ける so の後ろは does になります。
:::


## 4. the number of と a number of は別の主語

:::board
the number of applicants is
a number of students are
中心: number / students
:::

`the number of ...` は「…の数」なので中心は単数の `number` です。`a number of + 複数名詞` は「多くの…」で、後ろの `students` に合わせて複数扱いにします。`the/a` を見て分けます。

:::check check-29-agreement-advanced-04
question: 次の文の空所に入る語は? A number of students ( ) absent today.
choice: B|are
choice: A|is
answer: B
explanation: a number of + 複数名詞 は「多数の〜」で、複数扱いです。
:::


## 5. a lot of は後ろの名詞の数に合わせる

:::board
a lot of cold water is used
water = 不可算・単数扱い
:::

`a lot of` だけでは単数・複数は決まりません。後ろが複数可算名詞なら複数、不可算名詞なら単数扱いです。ここでは `water` に合わせて `is`、さらに「使われる」ので `is used` とします。

:::check check-29-agreement-advanced-05
question: 次の文の空所に入る語は? A lot of cold water ( ) to cool down a drying machine.
choice: A|is used
choice: B|are used
answer: A
explanation: water は不可算名詞なので、a lot of cold water 全体を単数扱いにして is used とします。さらに「使われる」なので受動態です。
:::


## 6. 相関接続は B に一致させる

:::board
Either my parents or my brother is coming.
Not only the students but also the teacher was surprised.
B = 動詞に近い主語
:::

`either A or B` と `not only A but also B` では、基本的に B に人称・数を合わせます。A が複数でも B が単数なら `is/was`。相関接続の形より、まず B を確認します。

:::check check-29-agreement-advanced-06
question: 次の文の空所に入る語は? Not only the students but also the teacher ( ) surprised at the result.
choice: B|was
choice: A|were
answer: B
explanation: not only A but also B が主語のときは、動詞を B に一致させます。the teacher は単数なので was です。
:::


## 教授からの課題

主語の中心語を囲み、数量表現なら中心語、相関接続なら B、`so/neither` なら助動詞の形を順番に確認して選択肢を比べましょう。
