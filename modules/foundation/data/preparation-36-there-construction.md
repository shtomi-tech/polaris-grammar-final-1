# There構文（存在・一致）

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

there構文は、後ろの名詞を「〜がある・いる」と紹介する形です。場所を表す`there`と分け、時制と後ろの名詞句の数にbe動詞を合わせます。

:::board
このセクションの問い
「thereは場所か、名詞を紹介しているか」
:::

## 1. 場所のthereとthere構文を分ける

:::board
場所: The keys are there.
紹介: There are two keys on the desk.
:::

`The keys are there.`の`there`は「そこに」という場所です。一方、`There are two keys ...`では、thereの後ろに紹介される名詞句があります。まずthereの働きを決めます。

:::check check-36-there-construction-01
question: 次の文の空所に入る語は? ( ) any seats left in the waiting room?
choice: A|Are there
choice: B|Is there
answer: A
explanation: any seats が複数なので、be動詞は are。be動詞をthereの前に出して Are there any seats ...? という疑問文にします。一般動詞用の does は使いません。
:::


## 2. 動詞の数は後ろの名詞句を見る

:::board
There is a problem.
There are two problems.
:::

there自身が単数・複数を決めるのではありません。`a problem`なら単数、`two problems`なら複数。be動詞を後ろの名詞句の中心に合わせます。

:::check check-36-there-construction-02
question: 次の文の空所に入る語は? The committee is reviewing the decision because there ( ) a number of reasons for the delay.
choice: B|are
choice: A|is
answer: B
explanation: a number of + 複数名詞 は「多くの〜」を表し、複数扱いです。there の後ろの中心となる名詞句が複数なので、現在形の are を使います。
:::


## 3. 時制をbe動詞に反映する

:::board
現在: There is / are ...
過去: There was / were ...
:::

`yesterday`など過去の手がかりがあれば`was/were`を選び、そのあと名詞句の数を見ます。時制と数を一度に推測しないのが安全です。

:::check check-36-there-construction-03
question: 次の文の空所に入る語は? There ( ) a sudden change in the schedule yesterday.
choice: A|was
choice: B|is
answer: A
explanation: yesterday が過去の時点を示し、後ろの実質的な主語 a sudden change は単数です。過去形の単数に対応する was を選びます。
:::


## 4. 疑問文と否定文はbeを動かす

:::board
疑問: Are there any seats?
否定: There aren't any seats.
:::

疑問文ではbe動詞をthereの前へ出し、否定文ではbe動詞の後ろに`not`を置きます。一般動詞用の`do/does`は使いません。

:::check check-36-there-construction-04
question: 次の文の空所に入る語は? There ( ) several empty tables in the hall.
choice: B|aren't
choice: A|isn't
answer: B
explanation: 後ろの several empty tables が複数なので、現在形のbe動詞は are。否定ではその後ろに not を置き、aren't とします。
:::


## 5. 長い名詞句でも中心を探す

:::board
There are a number of reasons for the delay.
中心: reasons
:::

`a number of + 複数名詞`は「多くの〜」なので複数扱いです。`for the delay`に近い名詞へ引っぱられず、紹介される名詞句の中心を確定します。

:::check check-36-there-construction-05
question: 次の文の空所に入る語は? There ( ) several reasons for the delay.
choice: A|are
choice: B|is
answer: A
explanation: there 構文の実質的な主語 several reasons が複数なので are です。
:::


## 6. there構文を解く手順

:::board
thereの働き → 時制 → 後ろの名詞句 → 数 → 語順
:::

まず場所か紹介かを分け、現在・過去を確認します。次にbe動詞の後ろの名詞句を囲み、中心語の数に合わせます。疑問・否定なら語順と`not`の位置を仕上げに確認します。

:::check check-36-there-construction-06
question: 次の文の空所に入る語は? There ( ) a small park near my house.
choice: B|is
choice: A|are
answer: B
explanation: there 構文では、後ろの実質的な主語 a small park が単数なので is を使います。
:::
