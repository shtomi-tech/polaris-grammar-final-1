# 仮定法の基本

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

仮定法は、現実の事実そのものではなく、現実から距離を置いた条件や結果を表します。まず「実際にはどうか」を確認し、次に条件と結果の時点をそろえます。

## 1. 現実の条件と反実仮想を分ける

:::board
If it rains, we will stay home.
If I were free, I would help you.
:::

前者は起こる可能性のある条件、後者は現実には自由でないという距離を含む仮定です。`if` があるだけで仮定法過去とは決めません。

:::check check-mood-subjunctive-basic-01
question: 次の文の空所に入る語は? If I ( ) you, I would accept the offer.
choice: A|were
choice: B|am
answer: A
explanation: 現在の事実に反する仮定で、主語がIでも were を使うのが基本です。
:::


## 2. 仮定法過去は現在の反実仮想

:::board
If + 主語 + 過去形,
主語 + would + 原形
:::

`If I had more time, I would read more.` は、現在の事実と反対の仮定です。形は過去でも、意味の時間は現在であることがあります。

:::check check-mood-subjunctive-basic-02
question: 次の文の空所に入る語は? I want to buy a new smartphone but I can't afford to do so. If I ( ) more money, I would buy a new smartphone.
choice: B|had
choice: A|was had
answer: B
explanation: 今はお金が足りないという現在の事実に反する仮定なので、If I had ... , I would ... の仮定法過去を使います。
:::


## 3. be動詞は were を使う

:::board
If I were you, I would accept the offer.
:::

仮定法過去の `be` は主語にかかわらず `were` を使うのが基本です。「私があなたなら」という現実から離れた条件を、形でも示します。

:::check check-mood-subjunctive-basic-03
question: 次の文の空所に入る語は? If I ( ) you, I would accept the offer.
choice: A|were
choice: B|am
answer: A
explanation: 現在の事実に反する仮定で、主語がIでも were を使うのが基本です。
:::


## 4. 仮定法過去完了は過去の反実仮想

:::board
If + 主語 + had + p.p.,
主語 + would have + p.p.
:::

`If I had left earlier, I would have caught the train.` は、過去に実際には早く出なかったという仮定です。条件も結果も過去の出来事として扱います。

:::check check-mood-subjunctive-basic-04
question: 次の文の空所に入る語は? If she ( ) earlier, she would have caught the train.
choice: B|had left
choice: A|leaves
answer: B
explanation: 過去の事実に反する仮定は if + had + 過去分詞 です。
:::


## 5. 助動詞で結果の可能性を変える

:::board
would → そうなるだろう
could → そうできたかもしれない
might → そうだったかもしれない
:::

条件の形が同じでも、結果側の助動詞で可能・確率のニュアンスが変わります。`would` だけを機械的に探さず、選択肢の意味を確認します。

:::check check-mood-subjunctive-basic-05
question: 次の文の空所に入る語は? If she had left the house five minutes earlier, she ( ) the bus.
choice: A|might have caught
choice: B|might catch
answer: A
explanation: 仮定法過去完了の主節は would have p.p. のほか could / might / should have p.p. にもなる。「あのとき5分早く家を出ていたら」という過去の事実に反する仮定に対応する結果は、過去の時点の内容として have p.p. の形にする。
:::


## 6. 条件と結果の時点をそろえる

:::board
現在の事実に反対 → 過去形 / would + 原形
過去の事実に反対 → had + p.p. / would have + p.p.
:::

仮定法の過去形は、単なる過去時制ではなく「現実との距離」を表すことがあります。条件・結果がいつの話かを先に日本語で書きます。

:::check check-mood-subjunctive-basic-06
question: 次の文の空所に入る語は? If she ( ) harder, she would have passed the exam.
choice: B|had studied
choice: A|studied
answer: B
explanation: 過去の事実に反する仮定は If S + had + p.p., S + would have + p.p. の公式で表す。
:::


## 7. 基本問題は四つの順で解く

:::board
1. 現実の事実を確認する
2. 条件が現在か過去か決める
3. 条件側の形を決める
4. 結果側の助動詞と完了を照合する
:::

形を暗記する前に、現実の時計を置きます。時計が決まれば、`were` や `had + p.p.` は候補をかなり減らしてくれます。

:::check check-mood-subjunctive-basic-07
question: 次の文の空所に入る語は? If I ( ) fluent in French, I could get that job in Paris.
choice: A|were
choice: B|am
answer: A
explanation: 現在の事実に反する仮定は If S + 過去形 で表し、主節は would 以外に could も使える。
:::


## 教授からの課題

条件文を「実際の事実・仮定・結果」の三行に分け、現在の反実仮想か過去の反実仮想かを説明してから解きます。
