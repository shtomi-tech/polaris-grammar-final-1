# 名詞・可算／不可算・複数

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

ここでは、空所や文中の語を名詞として分類します。まず名詞かどうか、次に可算・不可算、数、特定性の順に見ます。冠詞や数量詞の細かな選択は、次のセクションに渡します。

## 1. 名詞は人・物・事柄を表す

:::board
名詞: 人・物・事柄の名前
`Wisdom` → 事柄・考え
`can` → 助動詞 / `help` → 動詞
:::

名詞は、目に見える物だけでなく、考えや事柄も表します。意味だけでなく文中の働きを見て、助動詞・動詞・代名詞と区別します。

:::check check-15-nouns-articles-01
question: 次の文で、名詞として働く語はどれですか。 Wisdom can guide us.
choice: A|Wisdom
choice: B|can
answer: A
explanation: Wisdom は考えや事柄を表し、文の主語として働く名詞です。can は助動詞、guide は動詞、us は代名詞です。
:::


## 2. 可算か不可算かを決める

:::board
可算: a book / two books
不可算: water / information
不可算名詞に a/an は置かない
:::

`book`は一冊、二冊と数えられますが、`information`はそのままでは数えません。不可算名詞を個数に分けるときは、`a piece of information`のように単位を借ります。

:::check check-15-nouns-articles-02
question: 次の文の空所に入る語は? We need some ( ) about the train schedule.
choice: B|information
choice: A|informations
answer: B
explanation: information は不可算名詞なので、通常は複数形や an を付けず、many も使いません。
:::


## 3. 可算名詞は単数・複数を分ける

:::board
単数: a book / the book
複数: books / the books
不可算: water / the water
:::

単数の可算名詞には、`a/an`、`the`、所有格などの目印が必要です。複数形は種類全体を表せる場合があり、不可算名詞は語尾を増やして量を表しません。

:::check check-15-nouns-articles-03
question: 次の文の空所に入る語は? The shelves contain several ( ).
choice: A|books
choice: B|book
answer: A
explanation: several は複数の個体を表す数量詞なので、後ろには複数可算名詞 books を置きます。
:::


## 4. 無冠詞の複数とthe＋複数を分ける

:::board
Dogs are friendly.
犬という種類全体
The dogs are friendly.
特定の犬たち
:::

無冠詞の複数形は、種類全体について述べるときに使えます。`the dogs`は話し手と聞き手がどの犬か分かる形です。複数だからいつも`the`ではありません。

:::check check-15-nouns-articles-04
question: 次の文の空所に入る語は? As a general rule, ( ) reusable bottles reduce plastic waste.
choice: B|不要
choice: A|A
answer: B
explanation: 再利用可能なボトル全般という一般論を表す指定なので、複数名詞 reusable bottles は無冠詞にします。the reusable bottles は、文脈上どのボトルを指すか共有できる場合の形であり、今回の一般論には合いません。
:::


## 5. 不可算名詞は単位を借りる

:::board
advice / information / homework
some advice
a piece of information
an assignment
:::

`advice`、`information`、`homework`は通常不可算です。`many information`や`homeworks`とはせず、量なら`some advice`、個数を分けるなら`a piece of information`や`an assignment`のように表します。

:::check check-15-nouns-articles-05
question: 次の文の空所に入る語は? Monica got ( ) from her coach about how to hit the ball.
choice: A|some advice
choice: B|advices
answer: A
explanation: advice は通常不可算名詞なので、some advice とします。個数を示すなら a piece of advice の形にします。
:::


## 6. 名詞の分類を四つの順で行う

:::board
1. 名詞かどうか
2. 可算か不可算か
3. 単数・複数か
4. 特定されているか
:::

名詞問題では、いきなり`a`や`many`を選びません。まず四つの分類を行います。最後の「特定性」と、数に合う冠詞・数量詞の選択を、次のセクションで詳しく確認します。

:::check check-15-nouns-articles-06
question: 次の文の空所に入る語は? We need some ( ) about the train schedule.
choice: B|information
choice: A|informations
answer: B
explanation: information は不可算名詞なので、通常は複数形や an を付けず、many も使いません。
:::
