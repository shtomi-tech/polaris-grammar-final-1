# 動詞の型・基本語法

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

前の単元で文の骨格を見つけたら、ここでは動詞の後ろとの結びつきを見ます。前置詞の有無、直接目的語の有無、語ごとの型を順に確認し、最後に意味を照合します。

:::board
この単元の問い
「動詞の後ろには、何が置かれている？」
:::

## 1. まず前置詞の有無を見る

:::board
V + 名詞 → 直接目的語の候補
V + 前置詞 + 名詞 → 前置詞句
:::

`The cat is under the table.`では、`the table`は`under`の目的語です。動詞の直後に名詞があっても、前置詞が間にあれば直接目的語ではありません。まず形を分けます。

:::check check-02-verb-frames-01
question: 次の文の空所に入る語は? The student ( ) the answer carefully.
choice: A|considered
choice: B|arrived
answer: A
explanation: the answer という直接目的語を取れる他動詞は considered です。
:::


## 2. 自動詞と他動詞を区別する

:::board
自動詞: 直接目的語を取らない
他動詞: 直接目的語を取る
:::

`arrive at the station`の`at the station`は前置詞句です。一方、`considered the answer`では`the answer`が動詞に直接つながります。「何を？」は目安にとどめ、前置詞なしで名詞が結びつくかを確認します。

:::check check-02-verb-frames-02
question: 次の文の空所に入る語は? The student ( ) the answer carefully.
choice: B|considered
choice: A|arrived
answer: B
explanation: the answer という直接目的語を取れる他動詞は considered です。
:::


## 3. 前置詞の目的語は後ろの名詞

:::board
`under the table`
under = 前置詞
the table = 前置詞の目的語
:::

前置詞の目的語は、前置詞と結びつく後ろの名詞です。`under the table`全体が前置詞句で、`the table`だけが目的語です。動詞の目的語とは結びつく相手が違います。

:::check check-02-verb-frames-03
question: 次の文の空所に入る語は? It's already 10 p.m. I would like to ( ) home.
choice: A|go
choice: B|return to
answer: A
explanation: go home は「家へ帰る」という決まった型で、home の前に to を置きません。would like to go home とします。
:::


## 4. be動詞とbe助動詞を分ける

:::board
be + 形容詞・名詞 → 主語を説明
be + -ing / 過去分詞 → 助動詞
:::

`The room is quiet.`の`is`は主語の状態を表します。`She is running.`なら進行形を作る助動詞です。後ろの形を見て、beの働きを決めます。

:::check check-02-verb-frames-04
question: 次の文の `is` の働きは? She is running.
choice: A|進行形を作るbe助動詞
choice: B|主語の状態を説明するbe動詞
answer: A
explanation: `is running` の `is` は `-ing` 形と結び付き、進行形を作るbe助動詞です。`The room is quiet.` の `is` のように状態を表すbe動詞とは働きが違います。
:::


## 5. 命令文は原形から始まる

:::board
命令: (You) + 原形
否定命令: Don't + 原形
:::

`(    ) the instructions carefully.`では、主語`You`が省略されています。空所には原形の`Read`を置きます。主語が見えなくても、命令文の形を戻して考えます。

:::check check-02-verb-frames-05
question: 次の文の空所に入る語は? ( ) the instructions carefully.
choice: A|Read
choice: B|Reads
answer: A
explanation: 命令文は主語 `You` を省略し、動詞の原形から始めます。したがって `Read the instructions carefully.` です。
:::


## 6. go・lie・lay・discussは型を確認する

:::board
go home
lie（横たわる） / lay（置く）
discuss the problem
:::

`home`は副詞なので`go home`とします。`lie`は自動詞、`lay`は他動詞です。`discuss`は前置詞なしで目的語を取り、`discuss about`とはしません。意味だけでなく型を見ます。

:::check check-02-verb-frames-06
question: 次の文の空所に入る語は? We ( ) our plans with our teacher.
choice: B|discussed
choice: A|discussed about
answer: B
explanation: discuss は他動詞で、話し合う内容を前置詞なしで直接目的語に取ります。discussed our plans とします。
:::


## 7. lie（横になる）・lay（置く）・lie（嘘をつく）を区別する

:::board
lie - lay - lain - lying: 横になる（自動詞、目的語なし）
lay - laid - laid - laying: ～を置く（他動詞、目的語が必要）
lie - lied - lied - lying: 嘘をつく（自動詞、目的語なし）
:::

同じ`lie`でも、意味によって活用形が違います。「横になる」の`lie`は自動詞で`lie - lay - lain - lying`、「～を置く」の`lay`は他動詞で`lay - laid - laid - laying`、「嘘をつく」の`lie`は自動詞で`lie - lied - lied - lying`と活用します。`-ing`形はどれも語尾が`-ying`ですが、過去形・過去分詞（`lay`/`lain`/`lied`）で見分けます。目的語があるかどうかと、文の意味（体を横たえる／置く／嘘をつく）を確認します。

:::check check-tense-present-perfect-08
question: 次の文の空所に入る語は? I've been feeling sick, so I've been ( ) in bed all day.
choice: A|lying
choice: B|lied
answer: A
explanation: 「(体調が悪くて)横になっている」という意味の lie(自動詞)の -ing 形は lying です。lied は「嘘をつく」の lie の過去形・過去分詞で、ここでは意味が合いません。
:::


## 8. 目的語の並び方をまとまりで見る

:::board
take + 人 + 時間
cost + 人 + 金額
do + 人 + もの
regard A as B
:::

`It takes me two hours.`、`It costs me $25.`、`do me a favor`は語順ごと型です。`regard A as B`ではBがAを説明します。誰に何をするか、AとBがどう結びつくかを確認します。

:::check check-02-verb-frames-07
question: 次の文の空所に入る語は? It may ( ) us several months to finish the project.
choice: A|take
choice: B|cost
answer: A
explanation: It takes + 人 + 時間 + to do で「人が~するのに時間がかかる」です。take us several months の型を使います。
:::


## 9. 受動態になっても型を残す

:::board
raise + 人・動物
be raised = 育てられる
:::

`He was born and raised in London.`では、`raised`を「育てられた」と読みます。目的語を取る`raise`が受動態になった形なので、後ろに目的語を足しません。動詞の型と態を続けて見ます。

:::check check-02-verb-frames-08
question: 次の文の空所に入る語は? He was born and ( ) in London.
choice: B|raised
choice: A|grown
answer: B
explanation: born and raised は「生まれ育った」という定型的な組合せです。raised は「育てられた」という過去分詞です。
:::


## 10. 入試型は決まった骨格を崩さない

:::board
not so much A as B
「AというよりB」
空所の位置を型で確定する
:::

`not so much A as B`は「AほどではなくB」という比較表現です。動詞の意味だけでなく、空所の前後がどの型を作るかを確認し、最後に意味を照合します。

:::check check-02-verb-frames-09
question: 次の文の空所に入る語は? The problem is not so ( ) a lack of money as a lack of time.
choice: A|much
choice: B|far
answer: A
explanation: not so much A as Bで「AというよりむしろB」という意味になる。この文は「お金の不足というより時間の不足だ」ということを表す。
:::
