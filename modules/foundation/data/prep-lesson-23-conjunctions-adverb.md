# 従属接続詞・副詞節

![博士帽をかぶったハリネズミ教授](static/hedgehog-professor-original.png)

ここでは、後ろに節を導き、主節との時間・理由・対比・条件などの関係を作る従属接続詞を扱います。まず後ろの形、次に節の働き、最後に意味を確認します。

## 1. 主節と従属節を分ける

:::board
接続詞 + S + V
主節: 独立して文になる
従属節: 主節に関係を加える
:::

`Because it rained, we stayed home.`では、`we stayed home`が主節、`because it rained`が理由を加える従属節です。SとVがあるかだけでなく、接続詞が節をどう位置づけるかを見ます。

:::check check-12-conjunctions-01
question: 次の文の空所に入る語は? I stayed home ( ) I was sick.
choice: A|because
choice: B|and
answer: A
explanation: because は理由を表す副詞節を導きます。
:::


## 2. 節か名詞句かを先に見る

:::board
because + S + V
because of + 名詞
although + S + V
despite + 名詞相当
:::

`because it rained`は節、`because of the rain`は名詞句です。`Although he is a farmer`と`In spite of his being a farmer`も、後ろの形が違います。意味が近くても形を優先します。

:::check check-12-conjunctions-02
question: 次の文の空所に入る語は? ( ) a farmer, he never gets up at dawn.
choice: B|Despite he is
choice: A|Although he is
answer: B
explanation: although と even though の後ろには節、in spite of の後ろには名詞相当の his being が続きます。despite の後ろに節を直接置く Despite he is は不適切です。
:::


## 3. 時間・対比の関係を読む

:::board
while + S + V
while: 〜する間 / 〜する一方で
although/even though: 〜にもかかわらず
:::

`while I was living ...`は時間、`while others are developing`は対比です。`although`や`even though`は予想に反する内容を導きます。前後の関係を読み分けます。

:::check check-12-conjunctions-03
question: 次の文の空所に入る語は? Some countries are developed, ( ) others are developing.
choice: A|while
choice: B|before
answer: A
explanation: 一方の国々は発展しているが、他方は発展の途中だという対比です。二つの節を対比してつなぐ従属接続詞 while を使います。
:::


## 4. 条件表現は距離感を分ける

:::board
if: 条件
unless: 〜でない限り
even if: たとえ〜でも
in case: 〜に備えて
:::

`unless`は否定を含む条件、`even if`は条件を認めても結果が変わらない譲歩、`in case`は備えです。`whether ... or not`は「〜であろうとなかろうと」と読みます。

:::check check-12-conjunctions-04
question: 次の文の空所に入る語は? ( ) you agree or not, the decision has already been made.
choice: B|Whether
choice: A|If
answer: B
explanation: whether ... or not は「~であろうとなかろうと」という譲歩の副詞節を表す。
:::


## 5. now that・provided・as long asを読む

:::board
now that: 今や〜なので
provided that: 〜という条件で
as long as: 〜する限り
as far as I know: 私の知る限り
:::

条件や理由の表現は、後ろが節でも意味の焦点が違います。`provided that`は条件、`now that`は理由、`as long as`は継続条件として文脈に合わせます。

:::check check-12-conjunctions-05
question: 次の文の空所に入る語は? As ( ) as I know, the shop is closed today.
choice: A|far
choice: B|long
answer: A
explanation: 「私の知る範囲では」なので範囲を表す as far as です。
:::


## 6. so thatとso ... thatを分ける

:::board
so that + S + can/will: 目的
so + 形容詞 + that ...: 結果
:::

`Speak loudly so that everyone can hear.`は目的、`The box was so heavy that ...`は程度から生じた結果です。`so that`を一つの訳に固定せず、前後の関係を確認します。

:::check check-12-conjunctions-06
question: 次の文の空所に入る語は? Speak loudly so that everyone ( ) hear you.
choice: B|can
choice: A|must have
answer: B
explanation: so that は目的を表し、「みんなが聞けるように」という意味なので can hear が適切です。
:::


## 7. 接続表現・相関接続もまとまりで読む

:::board
not only A but also B
what is more = そのうえ
as is often the case = よくあることだが
:::

`not only A but also B`は左右を対等につなぎます。`what is more`や`as is often the case`は語句全体で接続の働きをする表現です。単語ごとに分解しすぎません。

:::check check-12-conjunctions-07
question: 次の文の空所に入る語は? She is not only intelligent ( ) also hardworking.
choice: A|but
choice: B|and
answer: A
explanation: not only A but also Bで「Aだけでなく Bも」という意味の相関接続詞になる。
:::


## 教授からの課題

①空所の後ろが節か名詞相当か、②時間・理由・対比・条件・目的・結果のどれか、③前後の意味関係、の順に確認して問題を解きます。
